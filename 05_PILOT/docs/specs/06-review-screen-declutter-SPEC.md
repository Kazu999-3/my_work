# SPEC 06: 記事承認画面の情報整理（ゴチャ付き解消）（05_PILOT）

## 目的
- 記事承認画面（/admin/review）のカードとフィルター領域の情報過多を解消し、「開いてすぐ判断できる」画面にする。機能やデータは変えず、見た目と情報の出し方だけを整える。

## 現状の問題（2026-11-20 本番を直接確認して実証済み）
1. **カード1枚の情報量が多すぎる**：タイトル、FOCUS（黄色枠）、即承認推奨／要確認バッジ、公開日・推定パッチ、動画種別、再解析版（事実N件）、教本統合ルート、辞典マージ項目5種（パワースパイク／強み／弱み／先出し／ビルド）、チャンネルボタン、文字数、日付、元動画リンク、「元の記事と比べる」、実戦エッセンス抜粋、アクション7個（詳細・修正／プレビュー／プレイリスト／再解析／破棄／分解／即時承認）がすべて常時表示され、1画面に2〜3枚しか入らない。
2. **フィルター領域も多層で画面上部を占有する**：チャンプ状態タブ、レーン別タブ、チャンネルのドロップダウン、並び替え6種、検索、「詳細」フィルター（種別・品質）、更新ボタンに加え、一括承認ボタン、一括選択、キーボードショートカットの説明文までが常時並んでいる。
3. **用語が重複・不明瞭**：「却下」（Xキー）と「破棄」ボタンが別々に存在し関係が分からない。「分解」と「再解析」の違いの説明がない。FOCUSの黄色枠の意味の凡例がない。
4. 未処理は188件（2026-11-20実測：複数チャンプ120件、チャンプ未定57件、チャンプ確定11件）あり、1件あたりの判断コストがそのまま滞留につながっている。

## やること
- [ ] **カードの表示項目を「判断に必要な最小限」に絞る**：一覧のカードに常時表示するのは、タイトル／対象チャンプの状態（確定・複数候補・未定）／推奨・要確認バッジ／パッチ鮮度／文字数／統合先／主要アクション（即時承認・プレビュー・詳細）のみとする。それ以外（辞典マージ項目の内訳、実戦エッセンス抜粋、元記事との比較リンク、再解析の事実数、元動画リンクなど）は「詳細・修正」の展開内またはプレビューの中へ移し、一覧では出さない。
- [ ] **アクションを整理する**：常時表示は主要な3〜4個に絞り、使用頻度の低い操作（プレイリスト追加、再解析など）は「その他」メニュー等にまとめる。キーボードショートカット（J/K/Space/A/X/D/P/E）は従来どおり使えること。
- [ ] **用語を統一し、説明を付ける**：「却下」と「破棄」の重複を解消する（どちらかに統一するか、両方残すなら違いを明記する）。「分解」「再解析」それぞれに短い説明（ツールチップまたは凡例）を付ける。FOCUS（黄色枠）の意味を凡例で表示する。
- [ ] **フィルター領域を簡素化する**：初期表示はチャンプ状態・レーン・検索・並び替えのみとし、低頻度の詳細フィルター（種別・品質）は折りたたみ（開閉式の「詳細フィルター」）に移す。ショートカット説明は常時表示をやめ、ヘルプアイコン等から見られる形にする。一括承認・一括選択のボタン自体は残す。
- [ ] **バッジの視覚的階層を整える**：バッジの種類と色を整理し、判断に関わるもの（即承認推奨／要確認／旧パッチ）だけが目立つようにし、それ以外は控えめな表示にする。
- [ ] **push 前に必ずローカルで `npm run build` を実行し、成功を確認してから push する。** ビルド結果を報告に含める。

## やらないこと
- 一覧の表示件数（50件）やページングの変更 — 今回は対象外（末吉の指示で不要と判断）。
- 承認・統合・分解・再解析・却下のロジックや、記事データそのものの変更（変えるのは見た目と文言だけ）。
- プレビュー生成の速度改善（今回は対象外）。
- 05_PILOT 以外の変更、および 05_PILOT 内でも /admin/review 以外の画面の変更（コーチページは別SPEC）。

## 完了条件
- ローカル `npm run build` 成功 → push → Vercel 本番デプロイ成功。
- 本番 /admin/review で：一覧カードが最小項目のみの表示になり、移した情報は展開・プレビューから従来どおり参照できる。用語が統一され、分解／再解析／FOCUS の説明が画面上で読める。フィルターの初期表示が簡素化されている。承認・却下・分解などの操作が従来どおり動く。

## 未決事項（エージェントが勝手に決めない）
- どこまで項目を削るかの最終判断は、実装後に末吉が本番を見て行う。迷う項目は「詳細側へ移す」を既定とし、一覧から消す（データ削除はしない）。
- 「却下」と「破棄」のどちらに統一するかは、両者の現行の挙動差を報告したうえで末吉が決める。挙動差が無いなら文言を1つに統一してよい。
