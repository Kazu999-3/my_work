# SPEC 04: 数字と表記の仕上げ（パイロット）

## 目的
SPEC 01（コミット 7a410de90a）のレビューで「部分的」「未対応」となった項目を仕上げ、画面ごとの数字の食い違いを解消する。

## 現状（2026-11-19 レビューで確認）
SPEC 01 で完了したもの: 審査内訳の排他化（合計一致）、カードの名前重複の表示修正、健全性監査の173基準化と異常行の検出・バナー表示。以下が残っている。

1. ダッシュボードの総数はラベルに「全173体」と書いただけで、表示値は従来のレコード数のまま。しかも「173体」という数字が UI 文言に直書きされており、新チャンピオン追加時に古くなる
2. レーン攻略ページ（/lane-guides）のレーン別件数（合計が176になる問題）が未対応。レーン攻略カードの数字に単位・ラベルがなく、何の数字か分からない（例: 41.6%）
3. レーン別件数の統一は注記（「複数レーン兼任を含む」等）で処理されたが、YouTube／ダッシュボード側の母数（56/56/56/41/49）の定義は未整理
4. 「要対応」件数 144 vs 145 の食い違いが解消されたか未確認
5. 旧パッチバッジは健全性監査画面のみで、審査画面や note 下書き側（26.21 の記事等）には付いていない
6. SPEC 01 で求めた「名称の出現箇所リスト」の報告が提出されていない
7. 異常行（Lee Sin/LeeSin、ヴァイ/Vi、template）の発生元の特定がされていない（検出と表示まで）

## やること
- [ ] ダッシュボードの総数を実値に統一する: 表示値を正本（champions_summary.json の実数）基準の集計に変える。UI 文言中の「173体」直書きをやめ、正本データから動的に取得した数を使う（今後チャンピオンが増えても文言が古くならないこと）
- [ ] レーン攻略ページの件数を統一する: /lane-guides のレーン別件数の定義を正本基準に揃え、合計が総数と矛盾しない形にする（複数レーン兼任の数え方を決めて画面に明記する）
- [ ] レーン攻略カードの数字に単位・ラベルを付ける: 「41.6%」のような数字が何を表すか（名称・単位・分母）がカード上で分かるようにする
- [ ] レーン別母数の定義を整理する: YouTube スカウトとダッシュボードのレーン別母数（56/56/56/41/49 等）が何を数えているか定義し、正本基準と矛盾する場合は揃える。揃えられないものは定義を画面に明記する
- [ ] 「要対応」144 vs 145 を切り分けて解消する: 2つの集計の母数と条件を比較し、片方が誤りなら直し、定義違いなら両画面に定義を明記する。切り分け結果を報告に残す
- [ ] 旧パッチバッジの適用範囲を広げる: 審査画面（review）の記事一覧にも、現行パッチと異なる記事に「旧パッチ」バッジを付ける。note 下書き側は対象外でよいが、その旨を報告に書く
- [ ] 名称の出現箇所リストを提出する: 「KTM PILOT / SOVEREIGN PILOT」「レーン攻略 / レーンガイド / レーン攻略バイブル」「ADC / BOT」の出現箇所（ファイル・画面）を一覧にして `05_PILOT/docs/specs/reports/SPEC04-naming-inventory.md` に置く。**名称の変更はしない**（報告のみ）
- [ ] 異常行の発生元を特定して報告する: 重複行（Lee Sin と LeeSin、ヴァイと Vi）と template 行が、いつ・どの処理で作られたか（投入スクリプト、同期処理、手作業か）を調査し、上記とは別の報告として同じ reports フォルダに置く。**行の削除・統合はしない**

## やらないこと
- 名称そのものの変更（製品名・レーン攻略の正式名称・ADC/BOT は未決事項）
- DB の異常行の削除・統合（発生元の報告まで）
- 認証まわり（SPEC 02 / 03 の範囲）
- 05_PILOT 以外のファイルの変更
