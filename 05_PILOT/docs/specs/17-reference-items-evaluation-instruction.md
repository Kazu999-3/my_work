# 指示文17 ― 参考資料への一次評価の追加

## 目的
reference_items の各資料に、Muse の一次評価（判定・行き先・取り込み方）を付けて、資料を見たときに「取り込み候補か、参考どまりか」が分かるようにする。

## 前提
- 指示文16（C群12件の追加登録）が完了し、reference_items が34件になっている状態で実施する

## 入力資料（このフォルダに同梱）
- `reference-materials-evaluation.md`：判定つき29件（code、verdict、target、adoption_note）

## やること
- [ ] reference_items に評価用のカラムを追加する（例：verdict、target_project、adoption_note。形式は既存の設計に合わせてよい）
- [ ] 評価データの29件を、code をキーに反映する
- [ ] ×／保留の5件（A5、A6、B10、B11、C5）は評価なし（NULL）のままにする

## やらないこと
- 既存の本文・要点・カテゴリ・URL等の変更
- 評価データにない文言の追加や、判定の変更（疑問があれば勝手に変えず報告する）

## 完了条件
- CLI（seed_reference_items.py）で評価付きの資料が引ける（必要なら --list の表示に判定を含める等の最小限の対応）
- 評価を付けた件数（取り込み候補9件／参考20件）を DAILY_LOG に報告する
- マイグレーションを使う場合は既存の仕組みに沿い、冪等に再実行できる形にする
