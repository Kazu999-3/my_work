# 指示文：SPEC 08 自動退避＆クローズの常駐運用をONにする

## 作業内容
実装済みの自動退避＆クローズ（scripts/auto_close_terminal_errors.py）を、常駐ワーカー（youtube_worker.py）の実行環境で有効化する。仕組み・対象ステータス・クローズ条件の変更はしないこと。スイッチを入れるだけの作業。

## 手順
1. 常駐ワーカーの実行環境に環境変数 `AUTO_CLOSE_UNANALYZABLE=1` を設定する（ワーカーの起動方法に合わせて .env 等、常駐プロセスが実際に読む場所に設定すること）。
2. `AUTO_CLOSE_DRY_RUN` が 1 のまま残っていないことを確認する（残っていたら解除する）。
3. 必要ならワーカーを再起動して反映する。

## 検証して報告すること
- ワーカーのログで、自動クローズのステップが「AUTO_CLOSE_UNANALYZABLE is OFF」でスキップされずに実行されていること。
- 現在エラーとして残っている終端エラー（error_generation / error_no_transcript / failed）の動画が、次サイクルで手動確認用プレイリストへ退避され、manually_closed になること。件数の前後（エラー件数、クローズ済み件数）を報告する。
- クローズされなかったものがあれば、その理由（再試行の途中など）も報告する。

## 背景
- 2026-11-20に滞留分48件の一括クローズは承認・実施済み。その後もワーカーの処理が進み、同日11:12時点でエラーは46件まで増えている（クローズ済みは145件のまま）。常駐の自動運用が入れば、今後は人の手なしで捌ける。
