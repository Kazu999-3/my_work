## C2 LoL Guide @lol_guide_jp ― スキルCD表示の規約論点（開発事例・競合）
- URL: https://x.com/lol_guide_jp/status/2121165245033107527
- 要点：スキルCDを画面に出しながらプレイするのは規約上ありか、という論点。CDはDataDragon API＋統計的スキルレベル推定、Live Client APIからは相手チャンピオン・ロール・レベルを取得する方式で「統計サイトを別モニターで見るのと本質的に変わらないのでOKでは」という見解。PilotのHUD設計に直結する論点。詳細画像3枚あり
- 本文：これを画面上に出しながらプレイするのは、規約的にありかなしか。出ているクールダウンは、ゲーム内の情報から取得しているわけではなく、通常のDataDragonのAPIから、出ているアイテムの候補とレベルに対してのスキルレベルは、統計情報の最も選択率が高いもの。ゲーム内のLive Client APIから取得しているのは、相手のチャンピオンとロール名とレベル。サブモニターがある人なら、別のモニターで、いろんな統計サイトのチャンピオンのページを見て、スキルのCDを把握とかはしてる人はいると思う。それと本質的には変わらないのでOKな気もするのだが。

- URL: https://x.com/BANDAL_PC/status/1999781347565469779
