# SPEC 20: 表示の矛盾・空表示・導線の修正

作成: 2026-11-22（Muse）
対象: 05_PILOT
根拠: 2026-11-22 の全量コード監査と同日の本番ブラウザ監査。監査報告書の項目番号（A-2、C-20 など）を併記する。本番確認で実際に再現したものを優先する。

## 目的
「数字が画面ごとに食い違う」「データがあるはずなのに 0 件・空と表示される」「失敗なのか正常なのか判別できない」を直し、初見でも壊れているように見えない状態にする。

## やること
- [ ] 1. **レーンキーの統一とコーチ導線の修正**（C-20）。
  - lane-guides は `JG`、コーチ側のレーン定義は `JUNGLE` で、`/coach?lane=JG` で開くとレーン選択状態にもジャングル向け見出し分岐にもならない。キーをどちらかに統一し、リンク経由で正しく選択状態になるようにする。あわせて ADC/BOT の表記・キーも画面間でそろえる。
  - コーチの対面内容がレーン指定に連動しない問題（本番確認：`?lane=MID` でも TOP 同士の Darius vs Aatrox のまま、本文もレーンと噛み合わない）の原因を調べ、レーンに連動させる。連動できない場合は、その理由を報告する。
  - コーチ初期表示の対面例がサンプルであることを明示する（試合後タブの「サンプル表示中」バナーと同水準に）。
- [ ] 2. **/library が 0 件になる問題**（本番確認＋A-3）。チャンピオン詳細では「ライブラリ攻略知見 15件」と表示されるのに、/library は待っても「0件」のまま。原因を特定して修正する。あわせて、検索0件時と取得失敗時で表示を分け、条件リセット・再試行への導線を出す（現状はどちらも「ただ空」）。
- [ ] 3. **/admin/youtube の一覧が空になる問題**（本番確認）。集計は「全件 2,474／完了 2,214／クローズ済み 256／エラー 4」と表示されるのに、一覧は「対象の動画はありません」で1件も出ない。原因を特定して修正する。
- [ ] 4. **数字の矛盾の解消**（本番確認）。
  - 「記事承認」の件数：/admin/review では191件、/admin/dashboard では338件。定義を統一するか、統一できない場合は各画面に定義（何を数えているか）を明記する。
  - /admin/dict-health の「実戦・確認済み 0/173」と、各行に入っている検証日（例：2026/8/27 admin）の矛盾。集計の定義を正し、表示を一致させる。
  - チャンピオン詳細の「苦手な対面 TOP 5」が全員勝率50%超（50.46〜51.18%）になる問題。選定ロジックかラベル（「苦手」の定義）を見直し、数字とラベルが矛盾しない表示にする。
  - /admin/dict-health と /admin/dict-maintenance の一覧で名前が二重表示される問題（「Yunara Yunara」「アーゴット アーゴット Urgot」）。日本語名・英語名の出し方を統一する。
- [ ] 5. **lane-guides の失敗表示と章の表示**（A-2＋本番確認）。
  - API取得失敗時に「まだ作成されていません」と誤表示せず、失敗であることと再試行手段を出す（`app/lane-guides/page.tsx:35-53,325-329`）。
  - 章番号の重複（第8章の見出しが複数回出る）を直す。
  - 「※該当言及なし」が大量に並ぶだけの章（第9・第10章）は、空の節を畳む・件数を出すなど、内容が空であることが一目で分かる表示にする。
- [ ] 6. **チャンピオン一覧・詳細の空状態と説明**（A-5、A-6、D-25）。
  - 検索・絞り込みで0件のときに、空状態の文言と条件リセットへの導線を出す（`app/_champions/ChampionListView.tsx:124-250`）。
  - 存在しない `?c=` を開いたときに「見つかりませんでした」と告知する（現状は無言で一覧に戻る）。
  - 一覧の冒頭に、この画面の目的を伝える見出しと一文を足す。
- [ ] 7. **見出し・目的説明・入手先の追加**（D-26、D-27＋本番確認）。/library と /note に見出しと目的の一文を足す。ログイン画面に、合言葉の入手先の案内を足す（Portal の /replay-paths と同様の一般案内でよい。具体的な共有先は書かない）。
- [ ] 8. **/overlay の行き止まり解消**（本番確認）。待機画面にトップへ戻る導線を足す。あわせて「試合待機中」表示について、LoL未起動なのか接続エラーなのかを区別できる表示にし、「LoLを起動してください」等の次の行動を示す。
- [ ] 9. **dict-health の日本語名検索**（C-24、`app/admin/dict-health/page.tsx:232-240`）。`jpName` を検索対象に含め、dict-maintenance と仕様をそろえる。
- [ ] 10. **/admin/youtube の「辞典合成を起動」の重複解消**（G-33）。同一ページに2箇所ある同機能ボタンを1箇所にまとめ、キューの一覧がページ上部からたどりやすい構成にする。
- [ ] 11. **note の公開メタの既定値表示の是正**（C-22、`app/note/page.tsx:84-96`）。実測値がない場合に固定の日付・閲覧数・いいね数等（'2026-10-28'、'25'、'13' 等）を実測のように表示しない。無い場合は出さないか「—」にする。
- [ ] 12. **パッチ表記の不統一の是正**（本番確認）。チャンピオン詳細「Patch 16.1」、コーチ「Patch26.23」、note「パッチ26.21」と3種が混在する。発生源（データソース）を特定し、同じデータなら表示形式を統一する。別のデータなら、各画面に出典が分かる表示にする。判断が要る場合は決めずに報告する。
