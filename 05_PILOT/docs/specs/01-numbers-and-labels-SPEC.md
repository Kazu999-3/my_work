# SPEC：数字と表記の統一（戦術パイロット）

対象：https://ktm-pilot.vercel.app （リポジトリ内 `05_PILOT`）
Antigravityへの渡し方：このファイルをリポジトリに置き「このSPECを読んで実装して」と指示する。

## 1. 目的
画面ごとに食い違っている数字・単位・名称を、単一の正本（データ実数と共通の集計）から表示するよう統一し、利用者と運用者の混乱をなくす。

## 2. 現状の問題（2026-11-19 本番ログイン確認＋コードレビュー）

### 数字の不一致
1. チャンピオン総数が画面ごとに違う
   - トップ（辞典）：すべて (173)。`src/data/champions_summary.json` の実数も173で、layout / manifest の「全173体」と一致（＝これが現時点の実数）
   - 健全性監査（/admin/dict-health）：全175体
   - ダッシュボード（/admin/dashboard）：「辞典（統合本文あり）176」
2. 記事の承認件数が合わない
   - /admin/review：総数「すべて (169)」だが内訳（確定5＋複数110＋未定68）の合計は183
   - ダッシュボードでは「記事承認178」
3. レーン別件数の定義が画面ごとに違う
   - トップのフィルター：TOP 23 / JG 29 / MID 14 / ADC 20 / SUP 26（合計112で総数173と合わず、主レーンのみか複数レーン込みか説明がない）
   - レーン攻略（/lane-guides）：TOP 29 / JG 47 / MID 31 / ADC 26 / SUP 43（合計176）
   - YouTube解析・ダッシュボードの母数：56 / 56 / 56 / 41 / 49
4. その他の合計ズレ
   - 未開拓：総数「60体」に対し、レーン別（18+21+18+26+5）の合計は88
   - 要対応：健全性監査144体 vs ダッシュボード145
5. パッチ番号の混在：現行は26.23だが、健全性監査の大半は26.22、note下書きの記事は26.21、「確認済み」の2体だけが最古の26.18。古いコンテンツに印がない
6. レーン攻略カードの数字に単位・ラベルがない（例：TOP「29件 2,719 3 41.6%」の41.6%が何の割合か不明）
7. 健全性監査の一覧に重複・不審な行がある：「Lee Sin」と「LeeSin」、「ヴァイ」と「Vi」、「template」という行。これが総数のズレ（173/175/176）の一因の可能性がある
8. トップのチャンピオンカードで「Aatrox Aatrox」「Ekko Ekko」のように同じ名前が2回表示される箇所がある

### 名称・表記の揺れ
9. 製品名：タイトル・layout は「KTM PILOT」、ログイン画面・ナビ見出し・HUD は「SOVEREIGN PILOT」
10. レーン攻略の呼び方が3通り：「レーン攻略」「レーンガイド」「レーン攻略バイブル」
11. ロール表記：ADC / ADC/BOT / BOT が混在
12. 画面名：ナビは「記事の承認」、ページ見出しは「生成記事の承認 ＆ 教本統合」。上部ナビ（正式名称）と下部ナビ（辞典/note/承認/攻略の略称）で表記ルールが違う

## 3. やること
- [ ] 数字の正本を1か所に寄せる：チャンピオン総数・レーン別件数・承認件数・未開拓数・要対応数は、各画面のハードコードや個別集計をやめ、共通の集計関数（またはAPI）から取得して表示する
- [ ] チャンピオン総数はデータ実数（現時点では summary の173）と常に一致させる。監査・ダッシュボード側が別の母数を数えている場合は、その定義（例：重複行や下書きを含むか）を画面上に明記するか、実数に揃える
- [ ] 承認の内訳が総数と一致するよう集計ロジックを直す。分類が重複する設計なら、重複する旨をUIに注記する
- [ ] レーン別件数の定義（主レーンのみ / 複数レーン込み）を決めて全画面で統一し、定義が自明でない画面には注記を出す
- [ ] 重複行（Lee Sin/LeeSin、ヴァイ/Vi、template）の発生元を特定して報告する。データの削除・統合はこのSPECでは行わず、報告を受けて別途判断する
- [ ] パッチ表示：現行パッチは1か所の取得（Data Dragon由来）に統一し、現行より古いコンテンツには「旧パッチ」バッジを付ける。コンテンツ側のパッチ値そのものは書き換えない
- [ ] レーン攻略カードの各数字に単位とラベル（記事数・文字数・対面メモ数・カバー率など）を付ける
- [ ] チャンピオンカードの名前重複表示（日本語名と英語IDが同一の場合）を直し、1回だけ表示する
- [ ] 名称統一のための洗い出し：KTM PILOT / SOVEREIGN PILOT、レーン攻略系の3表記、ADC/BOT の出現箇所を全てリスト化して報告する。統一の適用は未決事項の決定後

## 4. やらないこと
- チャンピオンデータの追加・削除・統合（重複行の削除を含む）
- 記事コンテンツやパッチデータの書き換え、データ再生成の仕組み変更
- 認証まわりの変更（Cookie・レート制限は別SPEC）
- レイアウトやデザインの変更

## 5. 完了条件
- [ ] 全画面でチャンピオン総数が一致し、データ実数と合っている
- [ ] 承認画面で内訳の合計と総数が一致する（または重複の注記がある）
- [ ] レーン別件数・未開拓数・要対応数が全画面で同じ定義・同じ値になる
- [ ] 旧パッチのコンテンツにバッジが付いている
- [ ] 名称の出現箇所リストが報告されている

## 6. 未決事項（エージェントが勝手に決めない）
- 正式な製品名（KTM PILOT か SOVEREIGN PILOT か。サブブランドとして使い分ける場合はそのルール）
- レーン攻略の正式名称（レーン攻略 / レーンガイド / レーン攻略バイブル のどれか）
- ロール表記の正本（ADC か BOT か）
- 重複行の処置（統合するか、片方を消すか）
