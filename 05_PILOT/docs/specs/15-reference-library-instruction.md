# 指示文15 ― 参考資料ライブラリ化

## 目的
Tactical Pilot のライブラリ機能で、LoL の知見だけでなく「AI活用・副業」の参考資料も管理・閲覧できるようにし、資料がチャットやMarkdownファイルに散らばる状態を解消する。

## 決定事項（2026-11-21 ユーザー決定）
- 保存先は **参考資料専用の別テーブル** とする。既存の `personal_knowledge`（LoL知見）には手を入れない。

## 現状（2026-11-21 Muse確認）
- 知見・記事は Supabase の `personal_knowledge` テーブルで管理され、/library と /admin/review（記事承認）がその上に載っている
- `personal_knowledge` はチャンピオン前提の設計（champion カラム、対面・コーチ連携）のため、AI・副業の資料は別テーブルが適切と判断した

## 入力資料（このフォルダに同梱）
- `reference-materials-ai-sidebusiness.md`：全22件のタイトル・著者・URL・要点・分類案
- `reference-materials-fulltext.md`：A群10件の全文（B群12件は要点メモのみが正）

## やること
- [ ] 参考資料専用の新規テーブルを作成する（例：reference_items。カラム案：タイトル、著者、URL、カテゴリ、本文、要点、全文あり/要点のみの区別、作成日）
- [ ] 参考資料を閲覧できる画面を用意する（表示場所は未決事項1）
- [ ] 一覧の22件を初期データとして投入する（全文があるものは本文、ないものは要点メモを本文として登録し、区別が分かるようにする）
- [ ] カテゴリ（AI活用／副業・販売の型／開発事例・競合）で絞り込めるようにする
- [ ] 既存の LoL 知見ライブラリの表示・動作を壊さない

## やらないこと
- 既存の personal_knowledge のLoL知見データの移行・変更
- コーチ機能や対面タブへの参考資料の混入（連携させるかどうかは未決事項2）

## 未決事項（エージェントが勝手に決めない）
1. 表示場所：/library にタブを追加するか、独立した画面にするか
2. コーチの自由質問など既存AI機能から参考資料を参照させるか、当面は閲覧専用か

## 完了条件
- 一覧の22件が Pilot 上でカテゴリ別に閲覧できる
- LoL 知見ライブラリ・記事承認・コーチに回帰がない（既存テストと本番確認）
- 投入した件数と、本文あり／要点のみの内訳を報告する
- ローカルで `npm run build` が通ってからプッシュする
