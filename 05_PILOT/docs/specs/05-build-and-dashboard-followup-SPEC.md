# SPEC 05: ビルド復旧とダッシュボード集計の仕上げ（05_PILOT）

## 目的
- 壊れている本番ビルドを復旧し、SPEC 04 で直したはずの数字が本番でまだ食い違っている問題を、原因から解消する。

## 現状の問題（2026-11-19 本番確認・コードレビューで実証済み）
1. **ビルドが壊れていて、直近3コミットがすべてデプロイ失敗している。**
   - Vercel のデプロイ失敗メール: 11674a0（17:09）/ 8908ae5（17:17）/ 8c7e86f（17:58）、いずれも `npm run build` が exit 1。
   - 原因として特定済み: `src/app/overlay/page.tsx` が `@/lib/lanePriorityCalculator`（`calculateLanePriority` / `MacroPriorityReport`）を import しているが、そのファイルがリポジトリに存在しない（11674a0 で追加されたオーバーレイのレーン主導権HUD）。
   - 本番はいまも aec388a（SPEC 04）の状態。名称統一・オーバーレイ改善・審査高速化は未デプロイ。
2. **運用ダッシュボードの集計が辞書ヘルスと一致しない**（本番実測）:
   - ダッシュボード「AI生成（最新パッチ）0 / 要更新 173」 vs 辞書ヘルス「AI最新生成 36 / 要対応 137」。同じ champion_facts を見ているはずなのに結果が違う。ops-dashboard 側の集計（行の取得方法・キー照合・最新パッチ判定のいずれか）が本番データで機能していない疑い。
   - ダッシュボード「辞典（本文レコード数/全173体）176」— 異常行（template / Lee Sin / ヴァイ）を含む生の件数が、正本173と並べて表示され続けている。
   - ダッシュボード「レーンガイド 0」 vs レーンガイドページには6件のガイドが表示される。
3. **審査画面の旧パッチバッジが機能していない様子**: 本番で確認した最初の50件すべてが「現行メタ」表示で、パッチ26.16（2026-11-04）や26.20の記事にも旧パッチバッジが付いていなかった（現行パッチは26.23）。
4. **ログイン画面の文言が実態と違う**: `src/app/login/page.tsx` に「この端末では1年間ログイン状態が保持されます」とあるが、セッションは SPEC 02 以降 30日スライディング。
5. **異常行が「見えない化」した**: 辞書ヘルスの異常警告バナーが消えた一方、DBの異常行は残っている（レコード数176が証拠）。SPEC 01 で入れた「検出して知らせる」仕組みが後退している。

## やること
- [ ] **ビルド復旧（最優先）**: `src/lib/lanePriorityCalculator.ts` を、overlay/page.tsx の利用箇所（引数・戻り値の型 `MacroPriorityReport`）に合わせて実装する。実装が困難な場合は、import と該当HUDブロックを取り下げてビルドを通し、その旨を報告する（勝手に仕様を変えない）。
- [ ] **push 前に必ずローカルで `npm run build` を実行し、成功を確認してから push する。** ビルド結果を報告に含める。
- [ ] **ダッシュボード集計の原因特定と修正**: ops-dashboard と dict-health で集計が食い違う根本原因を特定し（取得件数・キー照合・パッチ判定を本番相当データで比較）、両画面の「AI生成／要対応」数が一致するよう修正する。原因と修正内容を報告する。
- [ ] **辞典レコード数の表示を正本基準に統一**: ダッシュボードの「176」のような生件数表示をやめ、正本173基準の集計に合わせる。異常行の件数は、出すなら「異常行 N件」と明示して別枠で出す。
- [ ] **レーンガイド件数の一致**: ダッシュボードの「レーンガイド」数を、レーンページの実態（6ガイド）と一致させる。数え方の定義が違うなら、定義をページ側に合わせて統一する。
- [ ] **旧パッチバッジの判定修正**: 記事のパッチが現行パッチ（26.23）より古い場合に旧パッチバッジが付くよう、freshness 判定の原因を特定して修正する。再現条件（26.16 / 26.20 の記事が現行メタ表示になる）を修正後に解消していること。
- [ ] **ログイン画面の文言修正**: 「1年間ログイン状態が保持されます」を、30日スライディングセッションの実態に合う文言に変える。
- [ ] **異常行の可視化を戻す**: 辞書ヘルスに異常行（正本にないレコード）の警告表示を復活させる。表示のみで、削除・統合はしない。
