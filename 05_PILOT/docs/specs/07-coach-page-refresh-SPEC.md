# SPEC 07: コーチページのブラッシュアップ（05_PILOT）

## 目的
- AI戦術コーチ（/coach）を使いやすくする。レーンに合わない内容が出る不具合を直し、「AIコーチ」の名のとおり自由に質問できるようにし、入力の手間と結果の読みにくさを解消する。

## 現状の問題（2026-11-20 本番を直接確認して実証済み）
1. **レーン不適合**：試合前タブで TOP の対面（Darius vs Aatrox）を選んでも、「初動3分ルートの方針」がジャングル専用の内容（「味方ボットのリーシュを受けて最速フルクリア」「2:55 スカトル勝負」など）のまま表示される。レーンに応じた切り替えがされていない。
2. **自由に質問できない**：「AI戦術コーチ」と名乗りながら、質問を入力する欄がない。自チャンプ／対面相手を選ぶと定型の手順書が出るだけで、知りたいことを聞けない。定番マッチアップ例でも「一般的な流れ（この対面専用の手順は未登録）」と汎用文面になることが多い。
3. **Riot ID の入力導線が悪い**：ID 入力欄はページ最上部にしかなく、試合後タブなどでは未入力だと案内文だけで画面の大半が空。タブを切り替えるたびに入力のために上まで戻る必要がある。
4. **パッチ表記が古いまま固定**：弱みメモなどのパッチ表記が Patch 26.22 のままで、現行パッチ（26.23）に追従していない。あわせて、メモの文章が途中で切れたように見える箇所がある。
5. **スタッツ分析の結果が読みにくい**：内容自体は詳細で良いが縦に非常に長く、セクション切替ボタン（5大レーダー／チャンプ深掘り／コンディション／特性診断）が結果の中ほどに埋もれて見つけにくい。未入力時の使い方の案内も少ない。

## やること

### フェーズ1（既存画面の改善）
- [ ] **レーン不適合の修正（最優先）**：「初動3分ルートの方針」などレーン依存の内容を、選択中のレーンに合った内容に切り替える。レーン専用の内容が無い場合は、ジャングル用をそのまま出さず、「汎用方針」であることを明示した内容にする。再現条件：TOP 対面（Darius vs Aatrox）で JG 専用文面（リーシュ／スカトル等）が出ないこと。
- [ ] **Riot ID 入力の改善**：ID 入力欄をスクロールしても届く位置（上部固定など）に置くか、各タブから入力・変更できるようにする。未入力のタブには、入力すると何が見えるかが分かる案内と見本（サンプル表示）を出す。
- [ ] **パッチ表記の自動追従**：弱みメモ等のパッチ表記を、固定値ではなく現行パッチに追従させる（他画面で使っている現行パッチの取得方法に合わせる）。文章が途中で切れて見える表示は、全文が読める形（展開表示など）に直す。
- [ ] **スタッツ結果のナビ改善**：結果の先頭に結論の要約（強み・最大のボトルネック・次にやること）を置き、セクション切替は画面上部に固定表示して、スクロールせずに切り替えられるようにする。

### フェーズ2（自由質問の追加）
- [ ] **自由質問欄の追加**：試合前タブに、チャット形式で質問できる入力欄を追加する。選択中の自チャンプ／対面相手／レーンを文脈として引き継ぎ、その対面に即した回答を返す。回答には根拠（辞典・対面メモ等を参照した場合はその旨）を示す。
- [ ] 既存の AI 基盤（現在使っているモデル・API）の範囲で実装する。新しい外部 API キーや追加課金が必要になる場合は、実装前にその旨を報告し、末吉の判断を待つ。

### 共通
- [ ] **push 前に必ずローカルで `npm run build` を実行し、成功を確認してから push する。** ビルド結果を報告に含める。フェーズ1とフェーズ2は別コミットに分け、フェーズ1だけ先にデプロイできる状態にする。

- 記事承認画面（/admin/review）の変更 — SPEC 06 の担当。
- 05_PILOT 以外、および /coach 以外の画面の変更。

## 完了条件

- 本番 /coach で：TOP 対面で JG 専用文面が出ない。Riot ID が各タブから入力でき、未入力でも案内と見本が見える。パッチ表記が現行パッチと一致する。スタッツ結果の先頭に要約があり、セクション切替が上部からできる。自由質問欄で対面に即した回答が返る。
