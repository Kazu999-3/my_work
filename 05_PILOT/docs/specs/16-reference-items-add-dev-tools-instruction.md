# 指示文16 ― 参考資料の追加登録（開発・ツール12件）

## 目的
指示文15で作った参考資料テーブル `reference_items` に、Xブックマーク「開発・ツール」カテゴリの12件（C群）を追加登録する。登録の完了確認後に、ユーザーが該当ブックマークを解除する。

## 入力資料（このフォルダに同梱）
- `reference-materials-dev-tools.md`：C1〜C12のタイトル・著者・URL・要点・全文・カテゴリ

## やること
- [ ] C1〜C12の12件を reference_items に追加する（code は C1〜C12）
- [ ] カテゴリは資料の指定どおり：開発事例・競合 7件（C1〜C5、C7、C11）／ツール・設定 5件（C6、C8〜C10、C12）。「ツール・設定」は新カテゴリとして追加してよい
- [ ] 全12件ともポスト本文を取得済みなので has_fulltext は true。本文が短いもの・詳細が画像やリンク先にあるものは、要点にその旨が書かれているので要点もそのまま登録する

## やらないこと
- 既存の22件（A群・B群）の変更・削除
- personal_knowledge など他テーブルへの変更
- テーブル構造の変更（必要な場合は勝手に変えず報告する）

## 完了条件
- CLI（seed_reference_items.py の --list）で合計34件になり、C群12件が引ける
- 追加した件数とカテゴリ内訳を DAILY_LOG に報告する
- マイグレーションを使う場合は既存の仕組み（migrations フォルダ＋Actions適用）に沿い、冪等に再実行できる形にする
