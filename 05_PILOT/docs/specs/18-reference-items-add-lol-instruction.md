# 指示文18 ― 参考資料の追加登録（LoL 130件）

## 目的
reference_items に、XブックマークのLoL系ポスト130件（D群：LoL上達・戦術 113件／E群：LoL一般 17件）を追加登録し、AI活用・副業の資料と同じ場所で参照できるようにする。
なお今回はブックマークの整理ではなく保管が目的で、ユーザーはXのブックマークを残す。

## 前提
- reference_items に既存の34件（A〜C群）が登録済みの状態で実施する

## 入力資料（このフォルダに同梱）
- `reference-materials-lol.md`：D1〜D113、E1〜E17のタイトル・著者・URL・カテゴリ・要点・本文
  - 全件 has_fulltext は true（スレッドの続きを取得済みの23件は、続きを含む全文が本文に入っている）

## やること
- [ ] D群113件・E群17件を reference_items に追加する（code は D1〜D113、E1〜E17）
- [ ] カテゴリは資料の指定どおり「LoL上達・戦術」「LoL一般」（いずれも新カテゴリとして追加してよい）
- [ ] 評価カラム（verdict 等）は今回は付けない（NULLのまま。評価は別途指示する）

## やらないこと
- 既存の34件（A〜C群）の変更・削除
- personal_knowledge など他テーブルへの変更（LoL知見の正本はそちらであり、今回の資料を混ぜない）
- テーブル構造の変更（必要な場合は勝手に変えず報告する）

## 完了条件
- CLI（seed_reference_items.py の --list）で合計164件になり、D群・E群が引ける
- 追加した件数とカテゴリ内訳を DAILY_LOG に報告する
- マイグレーションを使う場合は既存の仕組み（migrations フォルダ＋Actions適用）に沿い、冪等に再実行できる形にする
