# Bot 指示文42：合同カウントを「実際の人数」で表示する（上の帯NGの可視化）

## 目的
土曜定期カスタムの募集カードで、見た目の人数と「合同1卓まであと◯名」が食い違う問題を直す。原因は「上の帯NG（繰り上げ拒否）」の人がロビー人数には含まれ、合同カウントには含まれないのに、そのことが表示されていないこと。ユーザー要望（2026-11-28）：「実際の人数に基づいたわかりやすい表示に変えてほしい」。

## 現状（2026-11-28、Muse のコード調査で確認）
- 合同カウント（`evaluateCombinedStatus`）は繰り上げ可の人だけで数えるため、「あと◯名」の数字自体は正しい。
- しかしロビー側の人数（バナーのロビー行・第1戦◯名）はNGの人も含めて数える。例：上位7名＋中初級3名（うち1名が上の帯NG）だと、見た目は計10名なのに「合同1卓まであと1名」と出て、理由が読めない。
- 誰が上の帯NGかは、カードのどこにも出ていない。20:00判定の合同確定メッセージでも「条件外（上の帯NG）の方 ◯名」と人数だけで、名前は出ない。

## やること
- [ ] **中初級帯の参加者行に印を付ける**：繰り上げ拒否（`tier_promotion_pref = 'never'`）の人にだけ、行に分かる印を付ける（表示例：行末に「（上の帯NG）」）。対象は土曜定期カスタムのカードのみ。DB経路（`formatParticipantDisplayLine`）とテキスト経路の両方で同じ表示になること。印が表示クリーニング処理（`cleanEntryLine` 等）で消えないこと、既存の参加形態・レーン・帯の判定パースを壊さないことを確認すること。
- [ ] **バナーの合同行に内訳を出す**：NGの人がいて単純合計と合同対象人数が食い違う場合に、対象人数の内訳が読める形にする。表示例：
  - 募集中：「🔥 募集中（合同1卓まであと1名／対象9名：上位7名＋中初級・繰上可2名）」
  - 確定時：「✅ 合同1卓 開催確定！（計10名・上位ベース：上位8名＋中初級繰上2名）」
  - NGの人がいない場合は従来どおりの表示でよい。文言の細部は、数字が矛盾なく読める範囲で任せる。
- [ ] **20:00判定の合同確定メッセージに名前を出す**：現在「条件外（上の帯NG）の方 ◯名 は今回は見学・次回優先枠となります」と人数だけの箇所に、対象者の名前も列挙する（メンションは付けない）。中初級ベース時の「通常上位」の方も同様。
- [ ] 変更後、NGの人がいる場合・いない場合の表示例を DAILY_LOG に残す。
- [ ] ローカルで Bot の構文チェック（既存の dry-run 手順）が通ることを確認してから push する。

## やらないこと
- 判定ロジック・成立条件・合同カウントの数え方そのものの変更（表示だけを変える）。
- 上位帯メンバー個人への印付け（格下サポートなしは既定の状態であり、合同（中初級ベース）で外れる場合の扱いは判定メッセージの名前列挙のみとする）。
- 日曜カード・都度募集カードの変更。
- 繰り上げ設定（Portal プロフィール）の保存形式の変更。

## 完了条件
- 上の帯NGの人がいる土曜カードで、バナー・ロビー行・合同行の数字が矛盾なく読めること（本番カードの再描画または次回カードで確認）。
- 上の帯NGの人がいないカードの表示が従来と変わらないこと。
- ユーザーの指示・合意があったかのような記述を DAILY_LOG にしないこと（根拠は本指示文）。
