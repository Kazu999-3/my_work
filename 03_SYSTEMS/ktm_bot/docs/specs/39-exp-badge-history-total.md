# Bot 指示文39：募集カードの経験バッジ（🔰）が常連にも付く問題の修正

## 目的
定期カスタム募集カードの参加者行に付く経験バッジ（🔰初参加／🌱ライト）を、Portal が表示している実際の通算試合数と一致させる。

## 現状の問題（2026-11-26、ユーザー報告＋Muse のコード調査で確認）
- 2026-11-25 12:00 投稿の土曜定期カスタムカード（DB連動描画）で、**運営者かずき（通算117戦以上、11-22時点で52勝65敗）を含む4人（かずき・kira・くらげ・left）に 🔰 が付いている**。エマにだけ付いていない。ユーザーがスクリーンショットで気づいて指摘した。
- 🔰 の定義（`src/utils/ktmRank.js` の `getPlayerExperienceBadge`）は「通算0戦＝初参加」。かずきは常連（👑、カードでは非表示が正しい姿）であり、**表示は間違い**。
- 原因の見立て（コードで確認済み）：
- DB連動カードの描画（`src/utils/recruitmentLedger.js` の `formatParticipantDisplayLine`）は、バッジ判定に `fetchPlayerRowsMap` が `ktm_players` テーブルから読んだ生の行（`total_games`、`games_top` 等のカラム）を使っている。
- 一方 Portal は通算試合数を `ktm_players` のカラムではなく **`ktm_match_participants`（試合履歴）を集計してマージ**している（`04_PORTAL/src/app/api/players/list/route.ts` ほか）。つまり `ktm_players` 側の試合数カラムは大半のメンバーで 0／null のままで、Bot だけがそれを見て「0戦＝🔰」と誤判定している。
- ランクとレーンは参加レコード（recruitment_participants）側の保存値から表示されるため正しく出ており、バッジだけが別データで外れている。
- 過去にも同型の事故がある（2026-10、名簿読み込み失敗で かずき107戦に 🔰）。今回は読み込み失敗ではなく、**参照するデータ自体が実態と乖離している**点が異なる。

## やること
- [x] 調査：本番 `ktm_players` の かずき（および kira 等）の行で `total_games`・`games_*`・`metadata.games` の実値と、`ktm_match_participants` を集計した通算試合数を突き合わせ、原因の見立てが正しいか確定させる。結果を DAILY_LOG に記録する。
- [x] 修正：Bot のバッジ判定が Portal と同じ通算試合数を使うようにする。第一候補は `fetchPlayerRowsMap`（またはバッジ判定の直前）で `ktm_match_participants` を集計し、Portal の `/api/players/list` と同じ定義で `total_games`（可能なら `recent_games_30d`・`days_since_last_match` も）をマージすること。集計の定義（対象テーブル・数え方）は Portal 側の実装に合わせ、二重定義を作らない。
- [x] テキスト経路のフォールバック描画（`src/handlers/buttons/periodicRecruit.js`）でも同じ誤判定が起きないか確認し、起きるなら同じ直し方を適用する（共通化できるなら共通化する）。
- [x] 本当に通算0戦の新規参加者には従来どおり 🔰 が付くことを確認する（判定基準そのものは変えない）。
- [x] デプロイ後、次回の定期カード（または再描画）で、かずき・kira 等の常連に 🔰 が付いていないことを確認する。
- [x] ローカルで Bot の構文チェック（既存の dry-run 手順）が通ることを確認してから push する。

## やらないこと
- 経験バッジの判定基準（0戦=🔰／1〜14戦=🌱／15戦以上は非表示等）そのものの変更。
- Portal 側の集計ロジックの変更。
- `ktm_players` への試合数カラムの書き戻し（バッチ更新）— 集計で読む直し方を優先し、書き戻しが必要と判断した場合は実施せず報告すること。

## 完了条件
- 常連（通算15戦以上）の参加者に 🔰／🌱 が付かなくなること。
- 本当の初参加者（通算0戦）には 🔰 が付き続けること。
- 調査結果（かずき行の実値と集計値の差）が DAILY_LOG に記録されていること。ユーザーの指示・合意があったかのような記述はしないこと（根拠は本指示文）。
