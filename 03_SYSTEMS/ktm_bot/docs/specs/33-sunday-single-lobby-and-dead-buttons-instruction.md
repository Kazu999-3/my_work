# 指示文33: ロビー分けは土曜のみに戻す・眠っているボタンハンドラ3系統の撤去

## やること

### 1. ロビー分け（帯別集計・判定）は土曜カードのみにする
- 指示文32で日曜（お祭り）カードにも入ったロビー分けを外し、日曜は従来どおり帯を分けずに全体で集計・開催判定する形に戻す。日曜は「ランク不問」のお祭り枠であり、帯で分けないのが前提。
- 土曜カードの2ロビー制（上位帯ロビー／中初級帯ロビー、各10名、境界は推定MMR 1450）はそのまま維持する。
- 日曜のリマインド・「あと1名」・20:00判定も、帯名指しでない従来の全体表記に戻す。
- 推定MMR未設定の参加者を中初級帯ロビーに入れる扱い（土曜）は、ユーザー確認済みのため変更しない。

### 2. 眠っているボタンハンドラ3系統を撤去する
- 指示文31の調査報告（`03_SYSTEMS/ktm_bot/docs/reports/31-unknown-buttons-investigation.md`）で「生成側が存在しない」と確認された以下のハンドラを削除する。
  - `opgg_scout`（OP.GGスカウティング、未配線のスタブ）
  - `approve_knowledge:`（ナレッジワンクリック承認、通知生成側が存在しない）
  - `quick_substitute_*`（旧仕様の残骸、生成側は 2026-10-03 に廃止済み）
- `bet_team:` は現役機能のため触らない。
- 削除前に、生成側が本当に無いことと、他からの参照が無いことを再確認すること。

## やらないこと

- Portal（04_PORTAL）の変更。
