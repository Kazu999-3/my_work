## 🔬 1. 指標の定義：全体平均ではなく「対面JGとの相対比較」

本モデルにおける全指標は、全プレイヤーの平均値ではなく、**「その試合で対峙している味方JG vs 敵JG」の直接比較**である。

- **KP (Kill Participation)**: ここでは割合（％）ではなく、**「Kill ＋ Assist の絶対数」**を指す。（例: 2K 3A ➔ KP=5）
- **Death**: 当該時間までの累計死亡数。
- **相対差**: `味方JGの数値 - 敵JGの数値`

## 🌾 3. なぜ「ファーム優位（CS/Gold）」だけでは勝てないのか？

「ひたすらファームして差をつければ勝てるのか？」という長年の疑問に対する実測データ：

| 10分時点での優位指標 | 優位側の勝率 |
| :--- | :---: |
| **JG Gold優位** | 59.10% |
| **JG XP（経験値）優位** | 57.14% |
| **JG CS優位** | 56.16% |

### 構造的要因の分析
1. **CSだけ勝っているケース**:
   - 自陣を狩り続けて100CSを取っていても、その間に敵JGがガンクを決め、味方レーンが4v5で崩壊していれば勝率は56%前後に留まる。
2. **ガンクばかりでファームを失うケース**:
   - 逆に無理なガンクを連発して自陣キャンプが腐り、レベル差（XP）がつくと中盤以降のオブジェクト戦でスマイト差をつけられて崩壊する。
3. **結論**:
   - **「死なずにファームを回しながら、条件が揃った要所（KP）にだけ顔を出す」**という両立状態こそが勝率74%の正体である。

## 🐉 4. オブジェクト先行と勝率の相関

| 条件 | 達成側の勝率 |
| :--- | :---: |
| **First Dragon（最初のドラゴン）取得** | **61.24%** |
| **15分時点でDragon獲得数が先行** | **67.20%** |

- ドラゴン先行は明確に有利を生むが、単独では74%のKP+Deathモデルには及ばない。
- つまり、「無理してドラゴンを触ってデスする」のは本末転倒であり、**「敵JGをキル/キル関与した安全なダウンテンポでドラゴンを回収する」**のが黄金律である。

## 💻 5. KTM Sovereign OS への実装仕様基準

本実証データは、以下のシステムアルゴリズムに直接組み込まれる。

### ① `05_PILOT` インゲームHUD
- 10分および15分のタイミングで、対面JGとのKP差・Death差を判定。
- `KP差 > 0 && Death差 < 0` ➔ 「🌟 勝利ボーダー（74%帯）達成中：無理なガンクを避け、ダウンテンポでオブジェクトへ」と表示。
- `KP差 <= 0 || Death差 > 0` ➔ 「⚠️ テンポ劣勢警告：無謀な交戦を停止し、通常キャンプ同期と逆サイドトレードを徹底せよ」と表示。

### ② `05_PILOT` 試合後タブ（Post-Match Review）
- 15分時点での相対数値をカード表示し、勝敗の主因を「JG相対ボーダーの達成可否」からAIが論理的に解説。
