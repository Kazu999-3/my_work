# 📥 帝国インボックス (00_INBOX)

本フォルダは、散らかった思考、Web記事クリップ、スマホからの殴り書きメモ、PDF資料などを**「何も考えずに放り込む」ための一時投函ポスト**です。

---

## 📜 運用ルール（ハシ ＆ TOMO原則）

1. **放り込むだけ（人間）**:
   - 分類やフォルダ分けで悩む必要はありません。ファイル名も適当で構いません。
   - Web記事のMarkdown、議事録の断片、思いつきメモ（`.md` または `.txt`）をこのフォルダにドロップしてください。
2. **自動構造化 ＆ 原本非破壊（AIワーカー）**:
   - `py scripts/inbox_worker.py` を実行すると、AIが内容を分析し、**TOMO式3層（Core Concept / Structured Points / Actionable Steps）**で構造化された正式ノートへ変換します。
   - あなたの投入した原本ファイルは、絶対に削除・上書きされず、`_archive/` フォルダへ安全に退避・永久保存されます。
3. **MOCへの自動接続**:
   - 変換されたノートは、帝国総合索引（`NEXUS_INDEX.md`）へ自動リンクされます。
