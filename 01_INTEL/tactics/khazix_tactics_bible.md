# ⚔️ カ＝ジックス (Kha'Zix) 対面戦術バイブル

## 📌 基本方針 ＆ パワースパイク
- **戦術概要**: パッシブ孤立判定による超絶バーストダメージと、キルリセット跳躍（E進化）による連続暗殺アサシンJG。
- **主要パワースパイク**: Lv6 (Q進化), 1stコア (プロフェインハイドラ / ゴーストブレード完成時), Lv11 (EまたはW進化)
- **即死キルライン基準**: Lv6孤立時: 飛びつき ➔ Q (孤立倍率) ➔ AA ➔ Wで相手HP 80%が消滅

---

## 🗺️ 3段階勝ちパターン手順書 (Matchup Blueprint)

### Phase 1 (Lv1〜2: 序盤主導権)
- **アクション**: 孤立した敵JGへの積極的インベード。川でのスカトル争奪やタイマンでファーストブラッドを狙う。

### Phase 2 (Lv3〜5: リコール・パワースパイク準備)
- **アクション**: 敵のサイドプッシュをブッシュで待ち伏せ。孤立した敵を1秒で暗殺し、即座にRステルスで離脱。

### Phase 3 (Lv6〜: オールイン ＆ 試合決定打)
- **アクション**: 集団戦では先陣を切らず、敵の主要スキルが落ちた瞬間、孤立した敵バックラインへ飛び込みキルリセットで連鎖暗殺。

## ⚠️ 検討して落とした選択肢 ＆ 罠ビルド (Rejected Options / 没理由)

### 🚫 罠アイテム・NGビルド
- **孤立が取れない敵構成（タンク偏重・密集構成）に対して無理に脅威を重ね積みすること**: 
  - *没理由*: 対面のパワースパイクや防御ステータスを軽視したビルドは失速の原因になるため非推奨。

### ❌ 実戦でやってはいけない地雷行動
- **集団戦の開幕で敵5人の真ん中に真っ先に飛び込むこと（即座にフォーカスされて蒸発する）**:
  - *没理由*: 相手のカウンターや即死トリガーを踏むため厳禁。
