## 1. チャンピオンの本質と勝利条件（コアコンセプト）

- **圧倒的な機動力を活かしたマップ支配**:
  Talonは、Eスキル（Assassin's Path）による壁越え機動力を武器に、通常のチャンピオンでは不可能なルートでマップを縦横無尽に駆けるアサシン・ジャングラーです。敵の予測を上回るテンポでマップを掌握し、敵チームに「どこにいても安全ではない」という心理的プレッシャーを常に与え続けます。
- **「ターン制」マクロとスノーボールの最大化**:
  LoLの本質は「自分だけが損なく自由に動ける時間（ターン）」を創出・維持することです。ミニオンウェーブの管理や、相手がローム・リコールでターンを消費した隙を突き、プッシュして自分のターンを得ることで、カウンタージャングルやオブジェクト介入の主導権を握ります。
- **オブジェクトよりもゴールド・リソース優先**:
  Talonの本懐はキルとゴールドによる爆発的なスノーボールです。ヴォイドグラブやドラゴンなどのオブジェクトに固執せず、自身のファーム、アイテムパワースパイク、そして敵ジャングルのキャンプ略奪を優先します。「敵がクリアしなかったサイドのキャンプはお前のもの」という非対称な交換（ケーキの盗み食い理論）を徹底し、敵をマップ上で迷子にさせます。
- **縦割りの徹底と「1レーンを勝たせる」思考**:
  全てのレーンを救おうとする受動的なプレイは、結果的に中途半端なファームを生み、敵ジャングラーの侵入を許します。ミッドレーンを境界線として片方のサイドを捨て、特定の有利なレーン（ボラタイルなレーン）を徹底的に育てる「選択と集中（縦割り）」を貫きます。

## 2. スキル運用・コンボ・固有メカニクス（ミクロ極意）

- **E（Assassin's Path / 壁越え）の極意とクールダウンリセット**:
  - 壁を飛び越えるたびに個別壁ごとのクールダウンがリセットされるメカニクスを完全に理解し、敵の視界を避ける「視界遮断ツール（フランクの起点）」として活用します。
  - 追撃、逃走、タワーダイブ時の安全な出入り、集団戦での側面侵入など、直線的ではない立体的なルート取りで敵を翻弄します。一度飛び越えたばかりの壁のクールダウンや、着地点に敵のCCが集中していないかの事前確認が必須です。
- **スキルオーダー**:
  - `W -> Q -> E` の順で最大化します。Wのウェーブクリア性能とキャンプ周回速度を最優先で確保します。
- **状況に応じた基本・バーストコンボの使い分け**:
  - **基本コンボ (W -> Q密着 -> AA -> パッシブ発動)**: Wの往復当てでスローを付与し、敵に密着してQを使用します。Qは近距離発動でクリティカルダメージとなり、パッシブ（Blade's End）の出血スタックを爆発させます。
  - **確実なキルを狙うQ始動コンボ (Q -> 即W -> R -> AA)**: 相手に反応する時間を与えずに素早くバーストダメージを叩き込むため、状況に応じてQから入り即座にWを重ねる選択も徹底します。
  - **バースト奇襲コンボ (R -> W -> Q -> AA)**: R（Shadow Assault）のブレードを広げた状態でステルス接近し、Wを当ててからQで飛び込み、戻り刃とパッシブを同時に爆発させます。
- **クルーグ等のファーム効率化テクニック**:
  - クルーグを狩る際、Wは使えるようになった瞬間に即座に撃ち、次のWのクールダウンが回るまでにキャンプを倒し切ることで、クリア速度を極限まで高めてジャングルのテンポを維持します。

## 3. 序盤の立ち回りとテンポ管理（Lv1〜6・ファーム・ガンク）

- **フルクリア主軸とリコール逆算**:

- **不安定なレーン（Volatile Lanes）の優先介入**:
  - フラッシュやイグナイトを既に消費した敵がいるレーンや、近接同士で激しいトレードが行われている「火がある場所」を最優先で狙います。味方のCCに合わせて確実にキルを回収します。
- **インベードとキャンプ略奪（ケーキの盗み食い理論）**:
  - 敵ジャングラーがボットサイドに見えたら、即座にトップサイドの敵キャンプ（ラプターやグロンプ）を奪いに行きます。相手のジャングルタイマーを自陣のキャンプ湧きと同期させ、徹底的にリソースを枯らすことで相手ジャングラーの存在価値を消滅させます。
- **ベースタイマーの徹底（25秒ルール）**:

## 5. 中盤・オブジェクト・集団戦のポジショニング

- **中盤のレベル差・サイドプッシュ運用**:
  - ドラゴンに固執せず、サイドレーンを素早くプッシュして敵に防衛を強要します。Eの機動力を活かして味方との合流や別サイドへの展開を高速で行い、マップの主導権を握ります。
- **集団戦におけるバックライン暗殺とフランク戦術**:
  - 正面からのエンゲージは自殺行為です。必ずサイドのブッシュや壁の裏といった「敵の視界外」からEで侵入します。
  - ターゲットは最も育っている、または最も脆い敵キャリー（ADC・メイジ）。敵の主要なCCスキルが吐き出された瞬間を狙い、一瞬でバーストを叩き込んでから即座に離脱する「ヒット＆アウェイ」を徹底します。倒しきれなくても、敵の主要スキルを強制的に吐かせて戦線離脱させれば十分な役割を果たしています。
- **スプリットプッシュ時の引き回し**:
  - 敵が複数人で対応に寄ってきたら、Eで壁を越えて華麗に逃走します。敵の時間を無駄に奪い、味方が別のサイドでオブジェクトやタワーを取るための時間と空間を創出します。

## 6. 🚨 絶対回避事項（NG行動リスト）

- **ゴールドを抱えたままの徘徊（オーバーターン）**:

- **視界がある場所への無謀な突撃・ガンク**:
  - 敵のワードや視界が確保されていると判明している場所へのガンクは、時間を無駄にするだけでなくカウンターガンクの餌食になります。
- **オブジェクトやキルを求めた無意味な突撃**:
  - 確信のないガンクや、自分のターンがない状態でのリコール・ロームは致命的なリソース損失を招きます。焦ってキルを欲しがり、タンクやCC持ちに正面から突っ込むのは厳禁です。
- **パッシブを意識しない雑なスキル回し**:
