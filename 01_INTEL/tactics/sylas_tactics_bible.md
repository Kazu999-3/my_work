## 1. チャンピオンの本質と勝利条件（コアコンセプト）

サイラス（Sylas）の本質は、「高いバーストダメージ」「優れた機動力」「敵の強力なウルトの再利用（奪取）」にあります。特にジャングル運用における核心は、**「効率的なフルクリアによる安定したレベル先行」**と**「空き時間の徹底的な有効活用」**の両立にあります。

サイラスはレベル上昇とスキル回転率・Wの回復量が直結するため、序盤のファームを疎かにして闇雲なガンクに固執するのは悪手です。相手のジャングラーのキャンプを1つ奪う、あるいは最初のガンクを完璧にカウンターすることで相手のテンポと心理を破壊し、10分〜15分の間にリソース差を覆せないレベルまで引き離す「15 MIN RULE」を体現することが勝利への最短ルートとなります。また、敵構成に強力なウルト持ち（Malphite, Jarvan IV, Swain, Nautilus, Twisted Fateなど）が存在する場合、サイラスの価値は極限まで跳ね上がります。

## 2. スキル運用・コンボ・固有メカニクス（ミクロ極意）

### スキルオーダー
- **優先順位**: W最大化 ＞ E最大化 ＞ Q上げ
- W（王者の領域）の回復量とバーストは生存・トレードの生命線であるため最優先で最大化します。Qの爆発および叩きつけダメージの両方をキャンプに当てることがファーム速度向上の鍵です。

### 基本コンボ・固有メカニクス
- **基本コンボ**: `E1` → `E2` → `W` → `AA` → `Q` → `AA`
- **パッシブ（ペトリサイト・バースト）の徹底**: スキルとスキルの間に必ず通常攻撃（AA）を挟み、攻撃速度上昇バフと範囲ダメージを漏らさず発動させます。
- **Eの運用テクニック**: 3.5秒の再発動猶予を最大限に活用します。キャンプに対してはパッシブAAを挟みつつギリギリまで再発動を待ち、スキルCDを効率よく回します。また、ダッシュ持ちの敵（Jarvan IVやカミールなど）に対しては即座にE2を撃たず、相手のブリンクを見てから合わせる「後出しE」が鉄則です。
- **ロケットベルトの併用**: `E2`の最中にHextech Rocketbeltを使用することで、敵の反応を遅らせる「角度変更」と射程の補完が可能です。
- **グローバルUltの活用法**: ツイステッド・フェイト（TF）などのデスティニーを奪った際は、`R（テレポート）` ➔ `E1` ➔ `E2` ➔ `AA` ➔ `W` ➔ `Q`のコンボで背後やブッシュの視界外から奇襲を仕掛けます。テレポート中は着地予兆が見えるため、着地後のアクションを即座につなげてください。

## 3. 序盤の立ち回りとテンポ管理（Lv1〜6・ファーム・ガンク）

### 序盤タイムライン（0〜10分）
- **クリア＆ルート**: ラプター → クルーグ → ラプター → レッドバフ → クルーグのルートなどで素早くレベル3に到達し、ボットレーンやトップレーンへ介入します。
- **サポート・チーム連携**: サポートの動き（視界取りやリコールタイミング）を常に注視し、マップ上の主導権を維持します。キャンプを回る際もサポートの動きを優先し、ガンクの起点として連携します。
- **カウンタージャングルとキャンプ強奪**: 敵ジャングラーの開始位置を予測し、逆サイドからスタートして「キャンプを1つ奪う」ことで相手のレベル先行を阻止します。
- **ガンク判断**: 味方が合わせられる状況かつ、確実にキルが取れる場合のみ実行します。

## 4. ビルドパス・パワースパイク・アイテム使い分け

### ルーン選択
- **征服者（Conqueror）**: 持ち前のサステインと戦闘継続能力を高める軸ルーン。
- **電撃（Electrocute） / ファーストストライク（First Strike）**: 序盤のバーストとスノーボールを最優先する場合の選択肢。

### コアアイテム＆ビルド方針
- **スタート**: スノーボールを加速させるために `Dark Seal` ＋ `Refillable Potion` を購入します。スタックが溜まればゲームの主導権を握れます。
- **1コア以降**:
  - **Hextech Rocketbelt / Luden's Companion**: 機動力を補い、Eの射程や角度変更を可能にする必須級アイテム。
  - **Lich Bane**: パッシブとの相性が抜群で、火力を大幅に底上げ。
  - **Zhonya's Hourglass**: 集団戦での生存率を高め、サイラスの強みである「Wのクールダウン（回復待ち）」の時間を稼ぐために不可欠。
  - **重症アイテム**: 高い回復力を持つチャンピオン対面では `Mortal Reminder` や `Oblivion Orb` を早期に挟み、サステインを抑制します。
  - **耐久・状況適応**: 敵がAD偏重の場合は `Seeker's Armguard` やポーション代わりにHPを確保する `Phage` の購入を検討します。

### パワースパイク
- ファーストリコールでのDark Seal購入時、レベル6（ウルト習得時）、そして1コア（Rocketbelt / Stormsurge）完成時が最大のキルラインとなります。

## 5. 中盤・オブジェクト・集団戦のポジショニング

### 中盤タイムライン（10〜20分）
- **オブジェクト管理**: ヴォイドグラブの優先順位を極めて高く設定します。グラブを獲得してタワープレートを削り、ゴールド差を強制的に広げます。ドラゴンを単独で狩る速度は遅いため、味方の寄りを待つか、キルを先行させてから触るのが鉄則です。
- **サイドレーン管理**: ウェーブをフリーズされた場合は別レーンへロームし、サイドを押し切る力がある時は留まって敵に対応を迫り、マップ他地点で人数有利を作ります。ローム用のプッシュは敵ウェーブより「1〜2体多く」調整し、タワーへの早すぎる到達を防ぎます。

### 終盤・集団戦の立ち回り（20分以降）
- **集団戦**: フロントラインを真っ向から張るのではなく、**側面（フランク）からの奇襲**を狙います。最も育っている敵、あるいは「奪うと強力なUltを持つ敵」をターゲットにし、E2でキャリー陣を捕らえてバーストで落とします。
- **バロン・視界制圧**: 無理にバロンを触るのではなく、視界を制圧して敵を釣る・孤立した敵をキャッチする動きを優先します。敵の強力なエンゲージスキルは `Zhonya's Hourglass` で完全にあしらいます。
