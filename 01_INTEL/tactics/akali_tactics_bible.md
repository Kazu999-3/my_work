## 📌 基本方針 ＆ パワースパイク
- **戦術概要**: 序盤のレーン戦は弱いため、Q（五連苦無）の先端ギリギリでのみカイティングし安全にCSを確保する。Lv3でスキルが揃い本格的なトレードが可能になり、Lv6到達時に確定キルラインが発生する。主導権を握ったら即座にオラクルレンズへ変更し、川や敵ジャングルの視界を消して暗殺角を作る。
- **主要パワースパイク**: 
  - **Lv3**: W（黄昏の帳）＋E（翻身手裏剣）による一方的トレード解禁
  - **Lv6**: R（無欠処刑）による長距離ワンコンボキル（全レーン介入可能）
  - **1コア完成**: ヘクステック・ロケットベルト（オルタネーターから積む）による接近バースト
- **メタ指標(26.18)**: tier: C / win_rate: 42.5 / pick_rate: 0.8 / ban_rate: 1.2

## 🗺️ 3段階勝ちパターン手順書 (Matchup Blueprint)

### Phase 1 (Lv1〜2: 序盤主導権)
- **アクション**: 最序盤は無理な殴り合いを完全回避。Lv1はQでミニオンのラストヒットだけを拾い、レーンを自タワー前へ引き込む。相手がCSやハラスのためにスキルを使った直後（相手のターン終了時）のみ、前に出て（アップムビン）Qの先端で一方的に削る。

### Phase 2 (Lv3〜5: リコール・パワースパイク準備)
- **アクション**: WとEが揃った時点でトレードを仕掛ける。
  - **基本トレード**: EやWがCD中は絶対に戦わない。
  - **対遠隔メイジ**: 相手が距離を詰めてこない場合、前衛ミニオンにEを当てて進入 ➔ Q ➔ W（帳） ➔ 強化AA ➔ E2で安全離脱。
  - **W（帳）活用**: 煙幕内では対象指定スキルを完全無効化できるため、相手の重要スキルを空振りさせて一方的に殴る。
  - **ファーストリコール**: 手持ち500G前後で「ダークシール＋詰め替えポーション」を最優先購入し、スノーボールの土台を固める。

### Phase 3 (Lv6〜: オールイン ＆ 試合決定打)
- **アクション**:
  - **基本ワンコン（フラッシュ不要）**: R1 ➔ E ➔ Q ➔ E2 ➔ 強化AA ➔ R2 ➔ Q ➔ 強化AA
  - **ADC暗殺コンボ（前衛無視）**: R1で前衛タンクを飛び越える ➔ 敵ADCにEを当てる ➔ E2進入 ➔ R2で即座にトドメ。
  - **タワーダイブコンボ**: 敵タワー下にW展開 ➔ タワー外方向へEを使って離脱 ➔ 外からスキルダメージ ➔ E2でタワー下へ再進入してキル＆離脱。
  - **集団戦**: 正面突破は厳禁。オラクルレンズで視界を消し、側面（フランク）や背後から潜入。WとEの出入り（アグロピンポン）で敵陣形を崩壊させ孤立キャリーを刈り取る。

チャレンジャーレベルの視点から、Akaliでチームファイトを制圧するための重要アクションを解説します。Akaliは単なるキルマシーンではなく、「状況に応じた入り方」と「リソース管理」がすべてです。

### 🕒 [03:36](https://youtu.be/jpl1b8lT3vA?t=216) - フランク（側面奇襲）の基本と角度選定

*   **🗺️ マクロ判断 (Macro)**: 敵がオブジェクト（ドラゴン・バロン）に視線を集中させている隙を突く。敵の視界がない場所（壁越し、草むら）から回り込み、敵のバックラインを孤立させる。
*   **💡 判断の理由 (Why)**: アカリは正面から突っ込むと敵のCC（硬いCC）で即死する。視界外から接近することで、敵ADC/サポートに反応時間を与えずパニックを誘発できるから。
*   **🎯 ミクロ・操作のコツ (How)**: 壁越しにEを当ててからRで突撃するコンボが基本。敵の主要CCが他者に使われた瞬間を狙ってエンゲージすること。
*   **🚫 避けるべき罠・没理由 (Rejected)**: 視界がある場所を堂々と歩いての接近。敵に察知され、CCを温存された状態で捕まると何もできずに蒸発する。

---

### 🕒 [09:03](https://youtu.be/jpl1b8lT3vA?t=543) - オブジェクト戦での敵ジャングラー・トラッキング

*   **🗺️ マクロ判断 (Macro)**: ドラゴン/バロン戦の直前、敵JGの「スマイト権限」を奪う動き。キルそのものよりも、敵JGをファイトから遠ざける、またはスキルを消費させることが目的。
*   **💡 判断の理由 (Why)**: 味方JGのスマイト成功率を上げるため。敵JGにプレッシャーをかけて「殴れない・近づけない」状態にすれば、オブジェクトの確保率が劇的に向上する。
*   **🎯 ミクロ・操作のコツ (How)**: 無理にバックラインを狙わず、敵JGにQ+パッシブAAを叩き込み、W（煙幕）でヘイトを逸らす。敵JGがスマイトを使えない状況を作るだけで勝利。
*   **🚫 避けるべき罠・没理由 (Rejected)**: 敵の重要ターゲット（ADC等）だけを追いかけて深追いし、オブジェクトの周囲から離れてしまうこと。

---

### 🕒 [10:28](https://youtu.be/jpl1b8lT3vA?t=628) - レーン主導権（Prio）を活かした寄り判断

*   **🗺️ マクロ判断 (Macro)**: ドラゴン湧き前のウェーブ状況。ウェーブが悪いならスキルを全投入して即座にプッシュ（クリア）し、戦闘に合流する。
*   **💡 判断の理由 (Why)**: 寄りが遅れると、数的不利でファイトが始まる。CSを捨ててでも人数有利を作ることが、レーン戦で負けていてもチームファイトで勝つための最低条件。
*   **🎯 ミクロ・操作のコツ (How)**: QやEを活用して最速でミニオンを処理。移動時はRを惜しまず、最短ルートで合流すること。
*   **🚫 避けるべき罠・没理由 (Rejected)**: 「あと1体CSを狩りたい」という欲。数秒の遅れが味方3人のデスに直結する。

---

### 🕒 [15:18](https://youtu.be/jpl1b8lT3vA?t=918) - イーブン／不利時の「フロント・トゥ・バック」戦術

*   **🗺️ マクロ判断 (Macro)**: 自分が育っていない（キャリーできない）場合の立ち回り。無理な裏取りをせず、味方のフロントラインの後ろに陣取り、近づく敵を削る。
*   **💡 判断の理由 (Why)**: 負けているアカリがフランクを狙うと、視界 ward に引っかかってデスするリスクが高すぎる。味方のピール（守り）を兼ねつつ、敵の前衛を処理するのが最も価値が高い。
*   **🎯 ミクロ・操作のコツ (How)**: 敵の最初のバーストスキル（CC）を味方が受けた後に戦場に入る。Qを連打してパッシブを回し、敵の突っ込みを防ぐ。
*   **🚫 避けるべき罠・没理由 (Rejected)**: 育っている時と同じ感覚で敵バックラインへダイブすること。装備差がない/負けている状態では、一人も倒せず自滅する可能性が高い。

### プロからのアドバイス
アカリの最大の強みは**「リセットによる再エンゲージ」**です。一度突っ込んで敵のスキルを消費させ、煙幕（W）やEで距離を取り、**「敵のCCが落ちたタイミング」**で再びR2でトドメを刺す。この「引きと攻めのリズム」を意識するだけで、勝率は劇的に変わります。
