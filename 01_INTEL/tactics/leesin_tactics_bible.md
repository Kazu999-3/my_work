# ⚔️ リー・シン (Lee Sin) 対面戦術バイブル

## 📌 基本方針 ＆ パワースパイク
- **戦術概要**: 圧倒的な序盤機動力とQ・Rインセクコンボによるプレイメイク型ジャングラー。
- **主要パワースパイク**: Lv3 (全スキル解放), Lv6 (R龍の怒り習得時)
- **即死キルライン基準**: Lv6時: Q-R-Q-Eコンボで約780 DMG (相手HP 70%圏内)

## 🗺️ 3段階勝ちパターン手順書 (Matchup Blueprint)

### Phase 1 (Lv1〜2: 序盤主導権)
- **アクション**: 敵JGへのインベード、または3キャンプ速攻Lv3ガンクでファーストブラッドを狙う。

### Phase 2 (Lv3〜5: リコール・パワースパイク準備)
- **アクション**: ワードジャンプからのR（インセク）で敵キャリーを味方に蹴り飛ばしてピックアップ。

### Phase 3 (Lv6〜: オールイン ＆ 試合決定打)
- **アクション**: 敵アサシンやダイバーから自陣ADCをピール（蹴り飛ばし防御）、または側面からのフラッシュR。
