# ⚔️ シン・ジャオ (Xin Zhao) 対面戦術バイブル

## 📌 基本方針 ＆ パワースパイク
- **戦術概要**: 序盤のタイマン最強格。Eの飛びつき、Qのノックアップ、Rの遠距離無敵フィールド。
- **主要パワースパイク**: Lv2〜3 (最序盤1v1), Lv6 (R遠距離砲火遮断)
- **即死キルライン基準**: Lv3時: フルコンボで相手HP 60%を削り切る
- **2026年最速フルクリア**: **2分49秒**（キャンプ0:55湧き / スカトル2:55湧きに **6秒先行**）

---

## 🗺️ 3段階勝ちパターン手順書 (Matchup Blueprint)

### Phase 1 (Lv1〜2: 序盤主導権)
- **アクション**: 川でのスカトル争奪やインベードを積極的に仕掛ける。序盤のデュエルで負ける相手はほぼ皆無。

### Phase 2 (Lv3〜5: リコール・パワースパイク準備)
- **アクション**: Wで遠距離から視界確保＆射程延長Eで急襲。Rを展開して敵バックラインからの射撃を遮断。

### Phase 3 (Lv6〜: オールイン ＆ 試合決定打)
- **アクション**: 敵アサシンやブルーザーをRで吹き飛ばして味方キャリーを守るか、敵キャリーに飛びついて分断。

## ⚠️ 検討して落とした選択肢 ＆ 罠ビルド (Rejected Options / 没理由)

### 🚫 罠アイテム・NGビルド
- **防具なしのフルヘイルブレード脅威ビルド（中盤以降に飛び込んだ瞬間に溶ける）**: 
  - *没理由*: 対面のパワースパイクや防御ステータスを軽視したビルドは失速の原因になるため非推奨。

### ❌ 実戦でやってはいけない地雷行動
- **Wを外した状態での強引な短距離E飛びつき**:
  - *没理由*: 相手のカウンターや即死トリガーを踏むため厳禁。
