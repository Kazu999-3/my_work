# ⚔️ ジャーヴァンIV (Jarvan IV) 対面戦術バイブル

## 📌 基本方針 ＆ パワースパイク
- **戦術概要**: EQノックアップとR（天崩地裂）による絶対的エンゲージと序盤ガンク特化。Lv2~3のガンクテンポでゲームを掌握する。
- **主要パワースパイク**: Lv2 (EQコンボ解放時), Lv6 (R習得時), 1stコア (プロフェインハイドラ / エクリプス完成時)
- **即死キルライン基準**: Lv6時: 約680〜740 DMG (相手HP 65%で即死圏内)

---

## 🗺️ 3段階勝ちパターン手順書 (Matchup Blueprint)

### Phase 1 (Lv1〜2: 序盤主導権)
- **アクション**: 赤バフ ➔ Lv2即ガンク、または3キャンプ即ガンク。EQの命中を最優先。

### Phase 2 (Lv3〜5: リコール・パワースパイク準備)
- **アクション**: 敵JGの位置を把握しつつカウンターガンク。EQを外した場合は絶対に深追いしない。

### Phase 3 (Lv6〜: オールイン ＆ 試合決定打)
- **アクション**: 集団戦で敵キャリーをRに閉じ込める。砂時計またはステラックの盾でバーストを耐える。
