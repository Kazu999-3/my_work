# ⚔️ エイトロックス (Aatrox) 対面戦術バイブル

## 📌 基本方針 ＆ パワースパイク
- **戦術概要**: Qの3連続スイートスポットとパッシブ回復による集団戦制圧型レイドボスファイター。
- **主要パワースパイク**: Lv4 (Qランク2), Lv9 (QランクMAX・CD大幅短縮), 1stコア (ショウジンの矛 / サンダースカイ)
- **即死キルライン基準**: Lv6時: R展開中のフルコンボで約850 DMG (相手HP 70%圏内)

---

## 🗺️ 3段階勝ちパターン手順書 (Matchup Blueprint)

### Phase 1 (Lv1〜2: 序盤主導権)
- **アクション**: Q1の先端でハラス。W（縄）が命中したら即座にEで位置を調整してQ2先端をヒットさせる。

### Phase 2 (Lv3〜5: リコール・パワースパイク準備)
- **アクション**: 敵タワーを削りつつ、ヘラルド・ドラゴン戦にテレポートで参加。Rを発動してキルリセットを狙う。

### Phase 3 (Lv6〜: オールイン ＆ 試合決定打)
- **アクション**: 前線で敵複数人にQ3スイートスポットを叩き込み、大量の回復を得ながら敵バックラインを破壊。

---

## ⚠️ 検討して落とした選択肢 ＆ 罠ビルド (Rejected Options / 没理由)

### 🚫 罠アイテム・NGビルド
- **耐久ゼロの初手脅威ビルド（CC耐性がなく、重傷を積まれた瞬間に即死する）**: 
  - *没理由*: 対面のパワースパイクや防御ステータスを軽視したビルドは失速の原因になるため非推奨。

### ❌ 実戦でやってはいけない地雷行動
- **E（ブリンク）を逃げや調整用ではなく、不用意に開幕で前方に吐ききること**:
  - *没理由*: 相手のカウンターや即死トリガーを踏むため厳禁。

### 🕒 [03:25](https://youtu.be/1JqwO5vWu0U?t=205) - ボットサイドへの奇襲ガンクとキル獲得

このシーンでは、Aatroxがトップレーナーとしての役割を超え、ボットレーンへ介入しゲーム序盤に大きなアドバンテージを築きます。

*   💡 **判断の理由 (Why)**:
    *   **レーンの状況把握**: ミニオンウェーブが敵側にプッシュされており、味方タワー下で安全にガンクを仕掛けるチャンス。敵ボットデュオは深く入り込んでいるため、逃走経路が限定されます。
    *   **ジャングラーの位置予測**: 敵ジャングラーが逆サイドに見えている、あるいはリコール中などでボットサイドにいない可能性が高いと判断。カウンターガンクのリスクが低いと見ます。
    *   **パワースパイク**: Aatroxは序盤のLv3以降、Qの多段ヒットとWの引き寄せによる強力なCCとバーストダメージを持ち、2v2や2v3の状況でも高い戦闘能力を発揮します。
    *   **ドラゴンへの布石**: ボットレーンに有利を作ることで、次のドラゴン出現時にオブジェクトへの主導権を確保しやすくなります。
*   🎯 **ミクロ・操作のコツ (How)**:
    *   **隠密性と侵入経路**: 敵ワードの死角となるジャングル深部やブッシュを活用し、相手に察知されないよう接近します。ボットの三角ブッシュや川沿いからのルートが有効です。
    *   **エンゲージの起点**: 敵が前に出ている場合、まずQ1（外側のスイートスポット）でエンゲージし、移動速度が低下したところを狙います。最も重要なのはW（冥府の縛鎖）を確実にヒットさせ、引き寄せることでQ2、Q3を当てやすくすることです。
    *   **コンボと追撃**: Q1 -> W -> Q2 -> E（ポジショニング調整） -> Q3 の基本コンボ。敵がFlashで逃げた場合は、AatroxのE（悪魔の飛翔）で追い、パッシブAA（デスブリンガー・スタンス）で追撃します。Qの合間にAAを挟むことで、ダメージを最大化します。
*   🚫 **避けるべき罠・没理由 (Rejected)**:
    *   **ウェーブ管理のミス**: 味方ミニオンがタワーに押し付けられている状況や、逆に大きくプッシュしている状況では、ガンクが難しくなります。特にタワーダイブはリスクが高く、相手にキルを与えかねません。
    *   **情報不足でのガンク**: 敵ジャングラーの位置や敵ミッドのロームが予測できない状況で深入りすると、カウンターガンクを受けて複数のキルを献上する可能性があります。常にミニマップで情報を確認しましょう。
    *   **スキルミス**: Q1やWを外し、エンゲージのチャンスを逃すと、敵に引かれてしまい時間とリソースの無駄になります。確実にヒットさせることを意識しましょう。

### 🕒 [08:15](https://youtu.be/1JqwO5vWu0U?t=495) - ドラゴン前のウェーブフリーズと視界確保

このシーンでは、オブジェクトコントロールのためにレーンウェーブを管理し、戦略的な優位性を確立するAatroxの判断が光ります。

*   💡 **判断の理由 (Why)**:
    *   **ドラゴン出現時間の調整**: ドラゴン出現まで時間があるものの、敵が先に視界を取りに来る可能性を考慮し、ウェーブフリーズで敵にプッシュの機会を与えません。これにより、敵がドラゴンに触りにくくなります。
    *   **敵ジャングラーの誘引とカウンター**: フリーズラインを維持することで、敵ジャングラーがウェーブを崩しにくる、あるいはドラゴン周辺の視界を取りに来ることを誘います。それを有利な位置で迎え撃つ準備をします。
    *   **味方の合流と時間稼ぎ**: 味方がまだオブジェクトに間に合わない場合、フリーズによって時間を稼ぎ、安全に合流させるための時間を作ります。
    *   **レーン主導権の維持**: フリーズを続けることで、敵レーナーにファーム機会を与えず、経験値・ゴールド差を広げます。また、敵のロームを牽制し、ミッドやボットへの介入を防ぎます。
*   🎯 **ミクロ・操作のコツ (How)**:
    *   **フリーズラインの維持**: 敵ミニオンを3～4体ほど残し、味方ミニオンとのバランスを取りながらタワーに押し付けないよう、AAで調整します。フリーズラインは、タワーの攻撃範囲外で、かつ自陣側に引き寄せた位置が理想です。
    *   **視界コントロール**: フリーズライン周辺のブッシュや、敵ジャングルへのワード設置を徹底します。Aatroxは単独で深入りしすぎず、味方ジャングラーと連携して視界を取り、安全を確保します。
    *   **Zone Control**: AatroxのQとWは広範囲のCCスキルであり、フリーズラインに近づく敵に対して強力なプレッシャーを与え、Zone Control（区域支配）を行うことができます。敵が不用意に近づけば、即座にエンゲージを仕掛けられます。
    *   **ピングの活用**: 味方に「フリーズ中」「ドラゴン準備中」「敵の動きに注意」などのピングを送り、意図を共有します。
*   🚫 **避けるべき罠・没理由 (Rejected)**:
    *   **フリーズの失敗**: ミニオンウェーブをタワーに押し付けすぎてしまい、フリーズが解除されると、敵は自由にオブジェクトに触れたり、ロームしたりできるようになります。
    *   **視界の欠如**: フリーズ中に敵ジャングルのガンクやミッドのロームに備えてワードを置かないと、不意打ちを受けてフリーズが台無しになるだけでなく、自身がキルされるリスクが高まります。
    *   **無駄なダメージ交換**: フリーズ中に敵との不必要なダメージ交換は避け、HPやマナを温存しましょう。いざオブジェクト戦になった際に不利を背負うことになります。

### 🕒 [14:40](https://youtu.be/1JqwO5vWu0U?t=880) - ヘラルド前での決定的な集団戦エンゲージと勝利

このシーンでは、Aatroxが集団戦におけるイニシエーター（開始役）として、その存在感を遺憾なく発揮します。

*   💡 **判断の理由 (Why)**:
    *   **オブジェクトの優先順位**: ヘラルドはタワー破壊とマッププレッシャーにおいて非常に重要です。このタイミングで集団戦を仕掛け、ヘラルド取得に繋げることが最大の目的です。
    *   **敵の位置取り**: 敵がヘラルドに固まっており、後衛が前に出すぎている、あるいはブッシュ内にまとまっているなど、AatroxのAoEスキルが複数にヒットしやすい状況を見極めます。
    *   **味方のバックアップ**: 味方のスキルクールダウンや位置取りを確認し、自身のエンゲージ後にすぐに味方が追撃できる態勢が整っているかを判断します。孤立したエンゲージは最も避けたい状況です。
    *   **パワースパイク**: AatroxはR（ワールドエンダー）がある状態で、高いサステインとダメージを持つため、集団戦で非常に強力です。
*   🎯 **ミクロ・操作のコツ (How)**:
    *   **エンゲージの起点**: 敵の視界外からFlash Q1で突入し、複数の敵にQ1のスイートスポットを当てます。これが集団戦の最も強力な開幕となります。Flashがない場合は、ブッシュからの回り込みや、味方CCに合わせたQエンゲージも有効です。
    *   **Rの発動タイミング**: エンゲージの直前、またはFlash Q1と同時にR（ワールドエンダー）を発動し、移動速度上昇と追加ダメージ、サステインを得ます。これにより、敵の主要なCCを避けつつ、前線を維持しやすくなります。
    *   **コンボとターゲットフォーカス**: Q1 -> W（敵キャリーを捕らえる） -> Q2 -> Q3 で敵を連続でノックアップさせ、味方キャリーがダメージを出しやすい状況を作ります。Aatroxはタンク役もこなせますが、敵の脅威となるADCやAPCを優先的に狙い、CCで動きを止め続けることが重要です。E（悪魔の飛翔）はQの合間のポジショニング調整や、AAキャンセル、スキル回避に使います。
    *   **サステインの活用**: R発動中のEとパッシブAAは、自身のHPを回復させる重要な手段です。これらを意識的に挟み込み、集団戦での生存能力を高めます。
*   🚫 **避けるべき罠・没理由 (Rejected)**:
    *   **孤立したエンゲージ**: 味方のサポートが届かない距離で一人で突っ込むと、敵に集中攻撃され、Rを発動してもすぐに溶けてしまいます。常に味方の位置を意識しましょう。
    *   **主要スキルのミス**: Q1やWを外すと、集団戦のイニシエート能力が著しく低下し、相手に反撃の機会を与えてしまいます。特にWは確実にヒットさせることが重要です。
    *   **CCスキルの考慮不足**: 敵に強力なハードCC（スタン、サプレッションなど）を持つチャンピオンがいる場合、無策に突っ込むと止められてしまいます。敵のCCが使われた後や、自身が浄化/QSSを持っている状況でエンゲージを検討しましょう。
    *   **ターゲット選択のミス**: 敵のタンクばかりを狙い続けても、後衛のキャリーは自由に火力を出し続けます。可能な限り、敵のダメージ源を狙いましょう。
