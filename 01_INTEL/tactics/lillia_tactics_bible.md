# ⚔️ リリア (Lillia) 対面戦術バイブル

## 📌 基本方針 ＆ パワースパイク
- **戦術概要**: 高い移動速度（MS）と持続魔法ダメージによるカイト型JG。集団戦での複数人睡眠（R）でゲームを決定づける。
- **主要パワースパイク**: Lv6 (R習得時), 1stコア (ライアンドリーの苦悶完成時)
- **即死キルライン基準**: Lv6時: 約620 DMG ＋ 睡眠追撃バースト (相手HP 55%圏内)

---

## 🗺️ 3段階勝ちパターン手順書 (Matchup Blueprint)

### Phase 1 (Lv1〜2: 序盤主導権)
- **アクション**: フルクリア最優先。スタックを維持して超高速でキャンプを回る。序盤1v1は避ける。

### Phase 2 (Lv3〜5: リコール・パワースパイク準備)
- **アクション**: RのCDごとにオブジェクトファイトまたはガンク。Q外周当てでMSを維持し続ける。

### Phase 3 (Lv6〜: オールイン ＆ 試合決定打)
- **アクション**: 敵前衛を殴ってスタックを溜め、EまたはフラッシュQから後衛を含めて複数人Rで睡眠をかける。

## ⚠️ 検討して落とした選択肢 ＆ 罠ビルド (Rejected Options / 没理由)

### 🚫 罠アイテム・NGビルド
- **耐久ステータスゼロのフルAPビルド（CCを1発受けた瞬間に即死する。ゾーニャ/リフトメーカー必須）**: 
  - *没理由*: 対面のパワースパイクや防御ステータスを軽視したビルドは失速の原因になるため非推奨。

### ❌ 実戦でやってはいけない地雷行動
- **Qスタックがゼロの状態での無謀なカウンターガンクや接敵**:
  - *没理由*: 相手のカウンターや即死トリガーを踏むため厳禁。
