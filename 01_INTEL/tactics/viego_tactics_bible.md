# ⚔️ ヴィエゴ (Viego) 対面戦術バイブル

## 📌 基本方針 ＆ パワースパイク
- **戦術概要**: 敵の魂を奪うパッシブ（君主の支配）による集団戦リセット型スノーボールファイター。
- **主要パワースパイク**: Lv6 (R習得時), 1stコア (クラーケンスレイヤー完成時)
- **即死キルライン基準**: Lv6時: 約720 DMG (相手HP 60%以下でRリセット確定)

---

## 🗺️ 3段階勝ちパターン手順書 (Matchup Blueprint)

### Phase 1 (Lv1〜2: 序盤主導権)
- **アクション**: 安定したフルクリアからスカトル争奪。Wのチャージスタンからのガンク。

### Phase 2 (Lv3〜5: リコール・パワースパイク準備)
- **アクション**: オブジェクト前の小規模戦（2v2 / 3v3）を仕掛け、最初の1キル（ファーストキル）を何としても奪う。

### Phase 3 (Lv6〜: オールイン ＆ 試合決定打)
- **アクション**: 敵フロントラインまたは瀕死の敵をフォーカスして即憑依。無敵時間を活用してスキルを回し続ける。
