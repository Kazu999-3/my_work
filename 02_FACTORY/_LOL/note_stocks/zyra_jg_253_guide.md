# LoL：2分53秒で試合を壊す「ザイラJG」の完全攻略

「ジャングル周回が遅くて、相手JGに先にガンクやカウンターを決められてしまう」
「APジャングラーを使いたいけれど、脆くて視界取りや集団戦で即死してしまう」

そんな悩みを抱える全ジャングラーに、今シーズン最強のTier1ピックとしておすすめしたいのが**「ザイラJG」**です。

KRチャレンジャーの天狐ハク氏が公開したデータによると、ザイラJGは**全ジャングル中ダメージ順位第5位**を誇りながら、**全チャンピオン中最速となる「2分53秒」でフルクリア**を完了できます。さらに植物による遠距離視界確保とアウトレンジからの自動攻撃により、極めて安全にゲームを破壊できるポテンシャルを持っています。

今回は、一般プレイヤーとチャレンジャーを分ける「2分53秒の種同期ミクロ」「初動の赤レンズ戦略」「集団戦の3段階ポジショニング」を完全解説します。

## 1. 2分53秒で全キャンプを溶かす「種同期ミクロ」

ザイラがなぜここまで周回が速いのか。それは「パッシブの種発生周期」と「Qスキルのクールダウン」を1秒の狂いもなく同期させているからです。

### ① 「0分55秒」にブッシュを出る
ザイラのパッシブ（種）は持続時間が30秒です。そして**「ブッシュ内にいる間はパッシブの種が生成されない」**という仕様があります。
最初のキャンプが湧くのは「1分28秒」。したがって、ブッシュを出てから種が生成されるまでの1秒ディレイを考慮し、**「0分55秒」ちょうどにブッシュから一歩踏み出して種を配置**し始めます。

### ② 「1分26秒」に植物を召喚する
キャンプが湧く2秒前の「1分26秒」に、あらかじめQを使って植物を立ち上げておきます。
これにより、湧いた瞬間に植物がオートアタック（AA）を開始すると同時に、**「次のパッシブの種が落ちるタイミング」と「QスキルのCDが明けるタイミング」が完全に一致**し、一切のロスなく連続で強化植物を召喚し続けられます。

## 2. 唯一の弱点「インベード」を封殺する初動ワード＆赤レンズ戦略

ザイラ最大の弱点は、初動に撒いた種を踏み荒らしに来る敵のインベードです。これを完璧に対策するルーティンが存在します。

1. **試合開始直後の防衛ワード**:
   - **下側陣営（青側）**: 自陣青バフ裏の主要通路にワードを設置。
   - **上側陣営（赤側）**: ラプター（鳥）前のリバー進入路にワードを設置。
2. **「Bキー即リコール」➔ 赤レンズ（オラクル）購入**:
   ワードを置いたら即座にリコールし、無料トリンケットを「オラクルレンズ（赤レンズ）」に交換してジャングルへ向かいます。
3. **2分53秒後の爆速レーン主導権**:
   敵JGより圧倒的に早い2分53秒で6キャンプを狩り終えたら、敵がまだファームしている間にレーンへ直行。相手が置いた防衛ワードを赤レンズで即座に消去し、**味方レーナーに強制的なプッシュ主導権をプレゼント**します。

## 3. カーサスやブランドには真似できない「ノーリスク視界確保」

他のAP高速周回ジャングラー（カーサスやブランド）は、移動スキルを持たないためリバーや敵ジャングルの視界を取りに行く際にキャッチされて即死するリスクを常に抱えています。

しかしザイラは、**Wの種を遠距離からブッシュへ投げ込み、QやEで植物化させることで「超長距離の安全視界」をノーリスクで確保**できます。暗闇のドラゴンピットやバロン裏に顔を出す（フェイスチェックする）必要は一切ありません。

## 4. 集団戦の鉄則：3段ポジショニング「引き ➔ 横 ➔ 前」

ザイラが集団戦で溶けてしまう人は、スキルを撃った後に前へ突っ込んでいます。プロが徹底しているのは以下の3段階のムービングです。

1. **【第1動：引き】植物を出したら、無条件に後ろへ下がる**:
   植物を召喚した瞬間、敵はザイラ本体を狙って飛び込んできます。ここで後ろへ下がることで敵のイニシエートをスカし、敵の突撃ルート上に植物の累積ダメージを叩き込みます。
2. **【第2動：横】敵の足が止まったら、横へスライドする**:
   植物のダメージとスローで敵の前衛が足踏みしたところで、横方向へムービングしながら第2陣のスキル（Eの捕縛やRのノックアップ）を狙います。
3. **【第3動：前】敵が削れたら、前へ詰めて制圧する**:
   敵の主要スキルが切れ、HPが削れたタイミングで初めて前進し、味方と共にタワーダイブや追撃を完了させます。
