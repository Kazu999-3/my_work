## 1. 「全部狩らないと損」という思考停止の罠

ジャングラー（JG）をプレイしていて、こんな経験はないだろうか？

「自陣のキャンプを順番に全部狩って、最後に赤バフを殴り終えたら、Botレーンで味方がデスしていた」
「フルクリアを終えてリバーに出たら、敵JGがすでにBotダイブを完了してドラゴンを触っていた」

多くのJGプレイヤーは「キャンプを残す＝ゴールドと経験値の損」という固定観念に縛られている。
青からグロンプ、ウルフ、ラプター、赤バフ、クルーグと、マップの端から端を円形にぐるりと回る「円形フルクリア」。
このルートは一見すると最も効率よくファームしているように見えるが、実は**「マップ上での無駄な往復移動（致命的なタイムロス）」**を大量に生み出している。

サモナーズリフトを支配するのは「ファームの量」ではない。**「盤面が動く瞬間にそこにいるか」というテンポ（時間）**だ。

欧州サーバー（EUW）で幾度となくソロランク1位に君臨し続ける最強のジャングラー、**Agurin（アグリン）**氏が実践する移動動線の極意――それが**「リニアクリア（直線動線）」**と**「赤バフスキップ理論」**である。

## 2. リニアクリア（Linear Clear：直線動線）の数学的思考

リニアクリアとは、**「次に行うべき決定的なアクション（目的地点）」を起点として逆算し、そこへ向かう最短経路上に存在するキャンプだけを一直線に狩り抜ける動線設計**を指す。

```mermaid
flowchart LR
    subgraph 円形フルクリア（従来の罠）
        A1[青バフ] --> A2[グロンプ]
        A2 --> A3[ウルフ]
        A3 --> A4[ラプター]
        A4 --> A5[赤バフ]
        A5 --> A6[クルーグ（孤立・往復）]
        A6 -. タイムロス発生 .-> A7[Botレーン（手遅れ）]
    end

    subgraph リニアクリア（Agurin流直線動線）
        B1[青バフ] --> B2[ウルフ]
        B2 --> B3[ラプター]
        B3 --> B4[Botレーン直行 / ダイブ / ガンク]
        style B4 fill:#f96,stroke:#333,stroke-width:2px
    end
```

従来のクリアは、端のクルーグや孤立したキャンプに寄り道することで、直線距離に対して1.5倍〜2倍の移動時間を費やしている。
一方、リニアクリアは一切の往復・蛇行を排除する。
「今、Botレーンが巨大ウェーブを押し込みそうだ」と判断したら、TopサイドからBotへ向かう直線上のキャンプ（グロンプ・ウルフ・ラプター等）だけを通過しながら狩り、寄り道せずにBotへ突入する。

## 3. なぜ赤バフを捨てるのか？（Why I skip Red Buff）

Agurinのプレイで最も衝撃的なのが、**「目の前にある赤バフをあえて殴らずに無視し、目的地へダッシュする」**という判断だ。

なぜ強力なバフと高額ゴールドを誇る赤バフをスキップするのか？
理由は明確に3つある。

### ① レーンの「クラッシュ猶予」は15秒しかない
味方レーナーが敵タワーに巨大ウェーブを押し込む（クラッシュさせる）瞬間、敵タワー下でダイブを仕掛ける、あるいはカウンターガンクを合わせられるウィンドウ（猶予時間）は、わずか15秒〜20秒程度しかない。
赤バフを叩いている15秒の間に、ウェーブはタワーに焼かれ、敵レーナーはリコールし、黄金のチャンスは永久に消滅する。

### ② 敵ジャングラーに対して「20秒の先手」を取る
敵JGがセオリー通りに赤バフやクルーグを叩いている最中、こちらは赤バフを切り捨てて目的地へ直行する。
これにより、敵JGよりも確実に20秒早くアクションを起こせる。
敵がファームしている間に、味方レーナーと2v1を作り、キルを奪い、タワープレートを2枚割り、敵陣の深い視界を制圧する。得られるリターンは、赤バフ1体の価値（約100ゴールド）を遥かに凌駕する。

### ③ キャンプは逃げないが、敵のミスは逃げる
赤バフは消滅しない。アクションが成功して敵をリコールさせた後、ゆっくり自陣に戻って狩ればいい。
仮に敵JGがこちらの赤バフを盗みに来たとしても、こちらはBotでキル＋タワー＋ドラゴンという圧倒的オブジェクト差を確定させているため、トレードとして大勝しているのだ。

## 4. リニアクリア実戦チェックリスト

試合中にこのマクロを発動するための4ステップ：

1. **目的地点の先行決定**:
   ウェーブの進行方向を見て、「30秒後にダイブ・ガンク・オブジェクトを起こす場所」を決める。
2. **直線ルートの選定**:
   現在地から目的地点へ向かう直線上にあるキャンプのみをターゲットにする。
3. **スキップの決断**:
   直線ルートから外れるキャンプ（赤バフ・クルーグ・孤立キャンプ）を狩ると、レーンのクラッシュタイミングに遅れると判断した瞬間、即座にスキップする。
4. **テンポの差で盤面を破壊**:
   敵JGより早く到着し、敵の防衛が整う前に数的優位で盤面を掌握する。

## 5. まとめ

- **円形フルクリアは往復移動によるタイムロスを生み、レーン変化に後手になる**
- **リニアクリアは「目的地への最短直線上にあるキャンプ」だけを狩る動線**
- **レーンの好機（ダイブ・クラッシュ）の猶予時間は数十秒。赤バフを叩く15秒でチャンスは死ぬ**
