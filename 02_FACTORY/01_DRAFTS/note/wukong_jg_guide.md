# 【LoL】集団戦を一人で破壊する！ウーコンJG低ランク脱出論

![ウーコンJG集団戦破壊論アイキャッチ](/note_assets/wukong_jg_thumb.jpg)

アイアンやシルバー、ゴールドのランク戦で、チャンピオン選択画面を開いた瞬間に頭を抱えるシチュエーションがあります。

「味方のTOPがグウェン、MIDがアーリ、BOTがジグス……全員魔法ダメージ（AP）に偏っている」

あるいは、

「相手のチームに突っ込んでくるファイターやアサシンが多く、味方のメイジやマークスマンが一瞬で溶かされて集団戦が崩壊する」

こんな絶望的な状況で、味方に「AD出して」「ピールして」とチャットを打っても何も変わりません。

僕たちがソロキューで勝ち上がるために必要なのは、**「味方のダメージバランスを自力で整え、相手の集団戦を一人で2回ノックアップして機能停止に追い込む圧倒的なキャリー力」**です。

その最強の回答が、ウーコン（猿）ジャングルです。

なぜなら、彼のアルティメットスキル（R）は、広範囲の敵全員を**2回にわたって宙へ跳ね上げる**という、LoL界でも屈指の理不尽な集団戦破壊兵器だからです。

机上の空論ではなく、実際に勝ち越した34戦のリアルな実践知をもとに、ウーコンJGで試合を一人で畳むための手順をすべて公開します。

## 1. なぜウーコンJGが集団戦の神なのか

低ランクの試合が負ける最大の理由は、「ゲーム後半、狭い川やドラゴン前で発生した5v5の集団戦で、誰を狙えばいいか分からず壊滅するから」です。

ウーコンはこの問題を、たった一つのボタン（R）で解決します。

### ① W（おとり）による視界欺瞞と安全なエンゲージ
普通のファイターが敵集団に飛び込もうとすると、近づいた瞬間に敵のCC（スタンやスロウ）を浴びて、何もできずにフォーカスされて蒸発します。

しかしウーコンには**W（戦士の幻影）**があります。
透明化しながら前方にダッシュし、元の位置に分身（デコイ）を残します。敵は目の前の分身に反射的にスキルを撃ち込み、重要なCCを無駄撃ちします。その間に、姿を消した本物のあなたが敵のキャリー（ADCやメイジ）の真横へ滑り込みます。

### ② R（つむじ風）の「2回ノックアップ」という暴力
ウーコンのRは、周囲の敵をなぎ払いながら高速回転し、触れた敵全員をノックアップ（打ち上げ）します。
これだけでも凶悪ですが、**ウーコンのRは「少し間を置いて、もう一度再発動できる」仕様**になっています。

1. 1回目のRで敵前衛と後衛をまとめて跳ね上げる。
2. 敵が着地した瞬間にQでアーマーを削り、さらに通常攻撃を叩き込む。
3. 敵がフラッシュで逃げようとしたり、反撃しようとした瞬間に、2回目のRを起動して**もう一度全員を宙へ跳ね上げる**。

この2回のノックアップを受けて生き残れるキャリーは低ランク帯には存在しません。味方がどんなにオロオロしていても、敵全員が宙に浮いている間に勝手にダメージを出して集団戦が勝利で終わります。

### ③ デコイも一緒に回転してダメージを2倍にする
Wで出した分身は、ウーコンがRを起動すると**分身も同時にRの回転を始めます**。
つまり、敵集団の真ん中にデコイを置いてからRを回すと、2つの竜巻が重なり合って敵のHPバーが文字通り消滅します。

## 2. 初動フルクリアとガンクの黄金ルート

ウーコンは序盤のジャングル周回がやや遅いと思われがちですが、スキルの回し方を覚えれば、HPを高く保ったまま3分15秒前後でスカトル前にアクセスできます。

### キャンプ狩りの鉄則：パッシブ（硬気功）を維持する
ウーコンのパッシブスキルは、モンスターや敵チャンピオンと戦っている間、**物理防御（AR）とHP自動回復がスタックしてどんどん硬くなる**特性を持っています。
これを利用するため、キャンプ間の移動はなるべく素早く行い、パッシブのスタックが切れる前に次のモンスターに触るのがコツです。

### 初動スキル取得と周回手順
- **Lv1**: **E（雲海連撃）**を取得。モンスター3体に突撃して攻撃速度（AS）を増加させ、通常攻撃で素早く削る。
- **Lv2**: **Q（強棒打）**を取得。通常攻撃の直後にQを押す「AAキャンセル」を徹底し、敵のARを削りながら大ダメージを与える。
- **Lv3**: **W（戦士の幻影）**を取得。中立モンスターの強烈な一撃を分身に身代わりさせることで、被ダメージを大幅にカットする。

### 最強のガンクルート：BotまたはTopへの「Wステルスガンク」
ウーコンのガンク成功率は、全ジャングラーの中でもトップクラスです。
茂みの手前からWで透明化してレーンに突入し、敵が気づいた時にはすでに射程内です。
1. **W（透明化）**で接近
2. **E**で飛びついて攻撃速度を上げる
3. **AA ➔ Q（AAキャンセル）**で大ダメージとアーマー低下
4. 赤バフのスロウを乗せて殴り続ける

Lv6以前でもフラッシュを確実に落とせ、Lv6以降はRのノックアップが加わるため、姿を見せた瞬間にキルが確定します。

## 3. 実戦勝率55.9%を叩き出した「ルーン ＆ ビルド」の結論

僕が34戦回して「低ランクの殴り合いで絶対に負けない」と確信した、王道の**ADファイター（征服者）ビルド**を公開します。

### ルーン：メイン栄華 ✕ サブ不撓

ウーコンはスキルと通常攻撃を激しく織り交ぜて戦うため、征服者のスタックが驚くほどの速さで溜まります。

- **メインツリー：栄華**
  - **キーストーン：征服者（Conqueror）**
    - E ➔ AA ➔ Q ➔ Rと回すだけで一瞬で12スタックが溜まり、攻撃力アップと回復効果が発動。乱戦になればなるほど死ななくなります。
  - **凱旋（Triumph）**: 集団戦でキルやアシストを取るたびにHPが回復し、連続キルを可能にします。
  - **レジェンド: 迅速（Legend: Alacrity）**: 攻撃速度を底上げし、ジャングル周回とAAキャンセルのテンポを快適にします。
  - **背水の陣（Last Stand）**: HPが減った状態での殴り合いで火力が跳ね上がり、パッシブの防御力と合わさって劇的な逆転勝ちを生みます。
- **サブツリー：不撓（Resolve）**
  - **ボーンメッキ（または息継ぎ）**: 敵ジャングラーとの序盤の川のタイマンで受けるダメージを大幅に軽減。
  - **超成長（Overgrowth）**: ジャングルモンスターを狩るたびに最大HPが永続増加し、後半のタンク性能を盤石にします。
- **ステータスシャード**: 攻撃速度 / アダプティブ / 伸びゆく体力

---

### コアアイテム：トリニティフォース ➔ サンダードスカイ

ウーコンの強さを120%引き出すためのビルドパスです。

#### 1手目：トリニティ・フォース（Trinity Force）
ウーコンにとっての絶対的な神器です。
Qのクールダウンが短いため、「シーン（強撃）」の追加ダメージがほぼ毎回のQに乗ります。攻撃力、攻撃速度、スキルヘイスト、そして移動速度のすべてがウーコンの性能に完璧に合致します。

#### 2手目：サンダード・スカイ（Sundered Sky）
敵チャンピオンへの最初の通常攻撃が確定クリティカルになり、減少HPに応じた回復が発生します。
集団戦で敵のADCやメイジに飛びついた瞬間に体力を半分吹き飛ばし、自分はモリモリ回復するという理不尽なタイマン性能を手に入れます。

#### 3手目以降の選択肢
- **ブラック・クリーバー**: 敵にタンクや硬いブルーザーが多い場合。Rの回転で敵全体の物理防御を一瞬で最大まで削り落とせます。
- **ステラックの篭手**: 敵のバーストダメージが高く、集団戦で真っ先に飛び込む必要がある場合。巨大なシールドで生存率が跳ね上がります。
- **デスダンス**: 敵が物理ダメージ（AD）主体の構成の時に積むと、集団戦で無敵の要塞と化します。

---

### 【追加紹介】試合を秒殺する「脅威アサシン型」ビルド

基本は上記のADファイター型が最も安定して勝てますが、**「相手チームが全員紙耐久（メイジ、ADC、アサシンばかり）」**の時にだけ選べる裏ビルドが存在します。

- **プロフェイン・ハイドラ ➔ オポチュニティ / 妖夢の霊剣**
- 立ち回り: 茂みからWで忍び寄り、E ➔ AA ➔ プロフェイン ➔ Q ➔ Rを一瞬で叩き込む。
- 敵のキャリーが何が起きたか理解する前に画面が白黒になります。スノーボールした時の破壊力は凄まじいですが、自分が捕まった瞬間に即死するリスクがあるため、初心者はまず王道のファイタービルドから入ることを強く推奨します。

## 4. やると即負ける「3大やらかし」

ウーコンを使っていて勝率を落とすプレイヤーは、決まって以下の3つのミスを犯しています。

### やらかし①：Wを移動用として適当に使ってしまう
ジャングル内を移動する際、早く移動したいからとWを押してしまう人がいます。
Wのないウーコンは、ただの棒を持った足の遅い猿です。敵の奇襲を受けた時に逃げられず、ガンクを仕掛ける時のステルス突入もできません。
Wは**「敵の目の前でスキルを吸わせる時」か「茂みからガンクを刺す瞬間」**まで絶対に温存してください。

### やらかし②：1回目のRだけで満足してスキルを回さない
Rを発動して敵を打ち上げた後、ただ回転が終わるのをぼーっと待っている人がいます。
Rの回転中、任意のタイミングでRを再発動（またはキャンセル）できます。1回目のノックアップが入ったら、すぐにQを挟んでダメージとアーマー低下を与え、敵が逃げようとした瞬間に2回目のRを被せるのが最高火力の出し方です。

### やらかし③：一人で視界のない敵陣に突っ込む
いくら集団戦が強いとはいえ、味方が画面の反対側にいるのに一人で敵5人の真ん中に飛び込んでも、2回のノックアップが終わった後にタコ殴りにされて終わりです。
ウーコンは**「味方が後ろにいて、ダメージを出せる距離にいる時」**に仕掛けてこそ、真価を発揮します。ミニマップで味方の位置を必ず確認してから飛び込んでください。
