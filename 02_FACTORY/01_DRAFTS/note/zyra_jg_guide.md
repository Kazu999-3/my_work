# 【LoL】ザイラJGで低ランクを抜ける超速ファーム＆集団戦攻略

アイアンやシルバーのランク戦でジャングルをやっていると、誰もが同じ壁にぶち当たります。

味方のレーナーがガンクに全く合わせてくれない。寄りを頼んでもミニオンを殴り続けて敵に挟まれる。敵のリー・シンやシン・ジャオと川で鉢合わせて殴り合い、味方のカバーが来なくてそのままデスする。

チャットで文句を言っても何も好転せず、マップを見るのも嫌になる。そんな経験が何度もあるはずです。

低ランクのソロQで勝率を劇的に上げるために必要なのは、味方に合わせてあげる仏のようなメンタルではありません。**味方がどんなに崩れても、一人で森を空にし、一人でオブジェクトを削り、一人で集団戦を破壊する完全自立型の立ち回り**です。

その答えが、ザイラジャングルです。

なぜ今、ザイラなのか。どう動けば敵のジャングラーと一切殴り合わずにゲームを終わらせられるのか。初動の秒数から対面のさばき方まで、すべて言語化してお伝えします。

---

## 1. なぜザイラJGが低ランク脱出の絶対解なのか

低ランク帯のジャングラーが勝てない理由は、実はとてもシンプルです。敵の得意な土俵に付き合ってしまうからです。

低ランクで人気のピックは、ビエゴ、リー・シン、ワーウィック、ノクターンといったタイマン殴り合いファイターです。彼らと川のスカトルや視界のない茂みで1v1の殴り合いを演じて負け、キルを渡してゲームを壊してしまう。

ザイラは、その殴り合いのリングにそもそも上がりません。

### 相手と殴り合わないから負けようがない

ザイラのファームは、すべて召喚した植物が引き受けます。中立モンスターの攻撃を植物が代わりに浴びるため、ジャングルを一周狩り終わった時点で体力が100%残っています。

川に出た瞬間に体力が6割しか残っていないファイターと、体力満タンで待ち受けるザイラ。この時点で圧倒的な有利が生まれます。

さらに、ザイラは射程外からスキルを叩き込むメイジです。敵が近づこうとしてもEのツルで足止めし、近づけなければ植物の集中砲火で削り落とす。相手の強みである接近戦を完全に拒否できるため、ミクロ勝負で負けるリスクがゼロになります。

### 味方を待たずに一人でオブジェクトを溶かせる

アイアンやシルバーで最もストレスが溜まる瞬間は、敵ジャングラーが反対側のマップに見えたのに、ピンを鳴らしても味方がドラゴンやヴォイドグラブに寄ってこない瞬間です。

普通のチャンピオンなら、味方が来なければ諦めるか、時間をかけて削っている間に敵のカバーが来て全滅します。

しかしザイラは違います。Wの種を2つ植え、Qで植物を咲かせるだけで、ドラゴンやグラブのターゲットが植物に向きます。自分は一切ダメージを受けず、恐ろしいスピードで中立オブジェクトのHPを消し飛ばせます。

味方がレーンでミニオンをCSしている間に、一人でサッとオブジェクトを取り切って立ち去る。味方に頼らないこの機動力が、低ランクの勝率を跳ね上げる最大の武器になります。

## 2. 2分25秒で森を空にする無傷フルクリア術

ザイラを使う上で最も重要なのは、初動のジャングルキャンプの処理速度です。

キャンプが湧く前から勝負は始まっています。以下の手順をそのままトレースしてください。練習モードで2〜3回走れば、誰でも確実にできるようになります。

### 0分41秒の種固定

試合が始まったら、味方にインベード警戒の合図を出しつつ、0分41秒までにラプター前の広場に直行します。

ザイラのパッシブスキルは、周囲にランダムで種を生成します。0分41秒より前にラプターの巣に入ってしまうと、戦いにくい位置に種が落ちてしまいます。41秒ジャストに定位置に立つことで、ラプターの巣周辺に2つから3つの種を確実に集められます。

### 0分55秒〜1分20秒: 赤バフとラプターの同時進行

1. キャンプが湧いたら、まずQスキルでラプター前の種を起動し、棘植物を咲かせます。
2. 植物にラプターの攻撃を受けさせながら、自分は赤バフの裏壁越しに通常攻撃を当てて赤バフを起動します。
3. 赤バフが壁を回って歩いてくる間に、ラプターは植物が自動で削り落とします。
4. 歩いてきた赤バフにQと通常攻撃を集中させ、体力を削り切ります。

この時点で、自分のHPバーは1ミリも減っていません。

### クルーグから青バフ側への渡り

クルーグへ移動する際、歩きながらWの種を2つ置き、Qで起動して大型クルーグを殴らせます。分裂した小型クルーグは、植物の範囲攻撃とポーションの回復効果で勝手に溶けていきます。

川を渡ってウルフ、青バフ、グロンプへ進む際も、常に原則は同じです。

- **原則1**: 中立モンスターの真正面に種を置かない。モンスターの攻撃範囲のやや外側に置き、植物が殴り続けられる時間を伸ばす。
- **原則2**: スキルを撃った直後にモンスターへ通常攻撃を入れ、植物の攻撃ターゲットを大型モンスターに集中させる。

この手順を狂いなくこなすと、**時計の針が2分25秒を指した時点で、森の全6キャンプが完全に消滅**します。

スカトルが湧く2分55秒に対して、実に30秒もの先行時間が生まれます。

この30秒の間にできることは無限にあります。体力が減っている敵のMIDレーンに裏からEを差し込むもよし、スカトルが湧く川の草むらに種を2つ仕込んで敵JGを待ち伏せするもよし。あなたが完全にゲームの主導権を握っています。

## 3. 5分00秒のオブジェクト単独融解マニュアル

フルクリアを終えてリコールし、最初の買い物を済ませたら、時計が4分50秒を回る頃にヴォイドグラブ、またはドラゴンへ向かいます。

低ランクの試合では、5分ジャストにオブジェクトに触るジャングラーはほとんどいません。大半の敵はウロウロと無駄なガンクを試みて失敗し、経験値をロスしています。

そこを完全に突きます。

### ヴォイドグラブを秒殺する配置

1. 壁の裏からグラブの巣の中央にWの種を2つ落とします。
2. Qを種の上に落とし、近接攻撃のトゲ植物（ソーンスピッター）ではなく遠距離攻撃の植物を咲かせます。
3. 植物が3匹のグラブの注意を引きつけるため、自分は巣の外側の安全な位置からスキルを回します。
4. スマイトを惜しまず1体目に落とし、分裂する前に処理を完了させます。

味方のTOPレーナーが押し込まれていようが、MIDがリコールしていようが関係ありません。敵がグラブの存在に気づく前に、3体すべてを自分のポケットに収めることができます。

### ドラゴン処理での絶対ルール

ドラゴンを一人で狩る際、唯一気をつけるべきなのはドラゴンのブレス攻撃です。ドラゴンのブレスは範囲攻撃のため、種をドラゴンの足元にまとめて置くと植物が一瞬でなぎ倒されてしまいます。

- 種はドラゴンの右斜め前と左斜め前に離して1つずつ置く。
- 1体目の植物が倒されたら、次のWを補充して咲かせる。
- 敵のボットレーンが上がってくる気配をミニマップで常に監視し、敵が寄ってきたら深追いせずEで足止めして即座に引く。

「触って、削って、ダメそうならEを置いてサッと引く」。この割り切りができるようになると、無駄なデスが完全に消えます。

## 4. 集団戦を一人で破壊する絶対法則

ゲームが中盤に進み、ドラゴン前やバロン前で5v5のにらみ合いが始まったとき、ザイラの真の破壊力が解放されます。

低ランクの集団戦は、お互いに誰が仕掛けるかも分からず、狭い通路でウロウロと固まる時間が必ず発生します。

この「ウロウロと固まった瞬間」こそが、ザイラの即死トラップの発動ポイントです。

### 視界外からのE ➔ W ➔ W ➔ Rコンボ

集団戦で絶対にやってはいけないのは、敵の正面に姿をさらして歩いていくことです。ザイラは移動スキルを持たないため、敵のCC（行動妨害）を1つでも食らえば即座に蒸発します。

必ず、壁の向こう側やコントロールワードで視界を消した茂みの中に潜んでください。

1. 敵のキャリーや集団が狭い通路を通る瞬間に、茂みの中から**E（捕縛のツル）**を伸ばします。
2. Eのツルが飛んでいる最中に、進路上へ**Wの種を2つ素早く設置**します（これでスロウ効果を持つツタ植物が2体咲きます）。
3. スネアが当たったのを確認した瞬間、敵集団の足元全体を覆うように**R（絞殺の茨）**を展開します。
4. 最後にQを重ねてダメージを最大化します。

Rの範囲内にいる植物は巨大化し、攻撃速度が150%上昇して狂ったような継続ダメージを叩き出します。そして2秒後、巨大なツルが敵全員を宙へノックアップします。

このコンボが決まった瞬間、相手チームのHPバーは消滅し、集団戦は戦う前から終わっています。

### 敵のアサシンに飛びつかれた時の自衛ミクロ

もし敵のゼドやカ＝ジックス、アカリが視界外からあなためがけて飛び込んできたらどうするか。

焦って逃げようとして背中を見せてはいけません。逃げスキルがないザイラは、背中を向けた瞬間に死にます。

敵が飛び込んできた足元、つまり**自分の真下にEを敷き、即座に足元にWを2つ置いてQとRを叩きつけます**。

相手があなたをキルするために足を止めたその場所で、植物とノックアップの集中砲火を浴びせるのです。ストップウォッチやゾーニャの砂時計があれば、コンボを放った直後に砂時計を使用します。相手は無敵のあなたを前に立ち尽くし、巨大化した植物に殴り倒されて返り討ちになります。

## 5. 低ランク頻出JGとの対面別攻略マニュアル

相手のジャングラーに合わせて、戦い方を少しだけ変えるだけで勝率はさらに跳ね上がります。

### vs ビエゴ / リー・シン（飛びつき系ファイター）
- **危険度**: 高（近距離でのタイマン）
- **戦術**: 川やジャングルで鉢合わせたら絶対に殴り合わない。相手がブリンクで距離を詰めてくる直線上にEを置き、スネアが入ったら植物を盾にして反対方向へ後退する。
- 相手がガンクを仕掛けてレーンに姿を見せたら、即座に反対側の敵のキャンプ（ラプターやグロンプ）に入ってすべて奪い尽くす。ファーム差で2レベルつければ、集団戦で相手は何の役にも立たなくなります。

### vs アムム / セジュアニ（タンク系ジャングラー）
- **危険度**: 低（カモ）
- **戦術**: 初手ライアンドリーの苦悶が完成した瞬間、相手のタンク性能は完全に崩壊します。植物の割合ダメージと炎上効果で、どんなに防具を積んだアムムも見る見るうちにHPが溶けていきます。
- 集団戦ではアムムの包帯（Q）の射線上にWの植物をサッと咲かせることで、包帯を植物でガードする職人技も可能です。

### vs リリア / カーサス（ファーム勝負メイジ）
- **危険度**: 中
- **戦術**: クリア速度の純粋なテンポ勝負になります。リリアも森を狩るのが速いですが、2分25秒のフルクリアを極めたザイラの方が一歩早く動けます。
- 先に川に出て視界を制圧し、相手が中立を狩っている最中に壁越しから植物を投げ込んで嫌がらせをし、リコールタイミングを狂わせます。

## 6. やると即負ける「罠ビルド＆地雷行動」

ザイラJGを使う上で、絶対にやってはいけない落とし穴があります。

### 初手マナアイテム（ブラックファイア・トーチ等）に逃げる罠

「スキルをたくさん撃つからマナが欲しい」と、初手にブラックファイア・トーチやルーデン・コンパニオンを買ってしまう人がいます。これは完全な罠です。

ジャングル内ではジャングルアイテムのパッシブ効果により、マナは猛スピードで自動回復します。ジャングルを回る上でマナアイテムは1ミリも必要ありません。

初手は**100%「ライアンドリーの苦悶」一択**です。

ライアンドリーが持つ最大体力の割合ダメージと戦闘継続時のダメージ増加効果があって初めて、中立モンスターも敵チャンピオンも一撃で溶かせるようになります。2手目はシャドウフレイム、3手目にゾーニャの砂時計。このビルドパスを絶対に崩さないでください。

### Eを適当に先撃ちして外す地雷行動

ザイラのスキルの中で、自分を守れる手段はEのスネアただ一つです。

視界のないブッシュを歩く際、索敵のために適当にEを撃ち、外れた状態で歩き続けるのは自殺行為です。Eのないザイラは、ただの足の遅いミニオンに過ぎません。

茂みの索敵は、**Wの種を放り投げるか、Qを撃って咲かせた植物に索敵させる**のが鉄則です。Eは敵の姿を捉え、確実に当たる瞬間か、飛び込まれた時のカウンター用として最後まで手元に残してください。

## 7. 今日から勝ち始めるためのアクションチェックリスト

最後に、次の試合からすぐに実践できるチェックリストをまとめました。

1. **試合前**: ルーンは「ファーストストライク」または「征服者/彗星」を用意。靴はソーサラーシューズを固定。
2. **0分41秒**: ラプター広場に立ち、種をラプター周辺に集める。
3. **2分25秒**: フルクリアを完了し、体力100%の状態で川のスカトルへ向かう。
4. **5分00秒**: ヴォイドグラブに先制アクセスし、植物にヘイトを取らせて単独確保する。
5. **集団戦**: 正面から姿を見せず、壁越しまたは側面茂みから「E ➔ W ➔ W ➔ R」で敵集団を分断する。
6. **防衛時**: 飛び込まれたら慌てて逃げず、自分の真下にコンボを撃ち込んで砂時計で受ける。

味方の愚痴を言っている時間はもう終わりです。

敵が右往左往している間に森を食い尽くし、ドラゴンを奪い、集団戦をツルの海に沈めて、一人でアイアン・シルバーの沼を突き抜けてください。
