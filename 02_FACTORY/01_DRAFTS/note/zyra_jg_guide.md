## 1. なぜザイラJGが低ランク脱出の絶対解なのか

低ランク帯のジャングラーが勝てない理由は、技術やエイムの差ではありません。**「相手の得意な土俵（殴り合い）にわざわざ上がっているから」**です。

低ランクで圧倒的な人気を誇るのは、リー・シン、ビエゴ、ワーウィック、シン・ジャオ、ノクターンといった接近戦ファイターたちです。彼らは1v1の殴り合いが生きがいです。川のスカトルや暗闇のブッシュで彼らと正面衝突し、ミクロの差や味方の寄りの差で負けてキルを渡してしまう。これが低ランクJGの典型的な負けパターンです。

ザイラは、そのリングに指一本触れません。

### 相手と殴り合わないから、絶対に負けようがない

ザイラのファームは、すべて召喚した植物が代わりに引き受けます。中立モンスターの攻撃を植物が壁となって浴びるため、ジャングルを一周狩り終わった時点であなたの体力は100%残っています。

川に出た瞬間に体力が6割に減っている敵ファイターと、体力満タンで涼しい顔をして待ち受けるザイラ。この時点で勝負はついています。

さらに、ザイラは射程外から一方的にスキルを叩き込む遠距離メイジです。相手が殴りかかろうと突っ込んできても、足元にEのツルを置いてスネア（移動不能）にし、近づけなければ植物の集中砲火で削り落とす。相手の強みである接近戦を100%拒否できるため、1v1で負けるリスクが構造的にゼロになります。

### 味方を待たずに一人でオブジェクトを消滅させられる

アイアンやシルバーで最もストレスが溜まる瞬間は、敵ジャングラーが反対側のマップに見えた絶好のチャンスなのに、いくらピンを鳴らしても味方がドラゴンやヴォイドグラブに寄ってこない瞬間です。

普通のチャンピオンなら、味方が来なければ諦めるか、無理に触って削っている間に敵のカバーが来て全滅します。

しかしザイラは違います。Wの種を2つ植え、Qで植物を咲かせるだけで、ドラゴンやグラブのヘイトが自動的に植物へ向きます。自分は1ミリもダメージを受けず、恐ろしいスピードで中立オブジェクトのHPを消し飛ばせます。

味方がレーンでCSを刻んでいる間に、一人でサッとオブジェクトを取り切って立ち去る。味方に頼らないこの機動力が、低ランクの勝率を跳ね上げる最大の武器になります。

## 2. 秒単位の初動タイムライン（0分00秒〜6分00秒）

ジャングル戦は、キャンプが湧く前から勝負が決まっています。

以下のタイムラインをそのまま覚えてください。練習モードで2〜3回走れば、誰でも確実に身体に叩き込めます。

| 時間 | あなたのアクション | 狙いとポイント |
| :--- | :--- | :--- |
| **0:41** | ラプター前広場に直行して静止 | パッシブの種をラプター周辺に2〜3個固定配置する |
| **0:55** | ラプター前の種をQで起動 ➔ 壁越しに赤バフへ通常攻撃 | ラプターを植物に削らせつつ、赤バフを同時に引っ張る |
| **1:20** | クルーグへ移動。Wを2つ置いてQで起動 | 分裂した小型クルーグは植物の攻撃で勝手に溶ける |
| **1:45** | ウルフ ➔ 青バフ ➔ グロンプを順次処理 | モンスターの攻撃範囲の外側に種を置き、植物を長持ちさせる |
| **2:25** | **全6キャンプ処理完了（フルクリア達成）** | **HP100%維持**。スカトル（2:55湧き）に**30秒先行** |
| **2:30〜2:50** | 敵の逆サイド侵入、またはMIDへEガンク | 敵JGがまだ森を回っている隙に川の主導権を完全制圧 |
| **2:55** | スカトルを秒殺して1stリコール | 稼いだゴールドで即座に靴と魔力アイテムを更新 |
| **4:50** | ヴォイドグラブの巣の裏へ移動 | 5:00ジャストの湧きに先制アクセス |
| **5:00** | 植物を壁にしてヴォイドグラブ3体を単独処理 | 味方が寄らなくても一人で安全にオブジェクト獲得 |

### 0分41秒の「種固定」の極意

試合が始まったら、味方にインベード警戒の合図を出しつつ、0分41秒までにラプター前の広場に直行します。

ザイラのパッシブスキルは、周囲にランダムで種を生成します。0分41秒より前にラプターの巣に入ってしまうと、戦いにくい変な位置に種が落ちてしまいます。41秒ジャストに定位置に立つことで、ラプターの巣周辺に2つから3つの種を確実に集められます。

### 赤バフとラプターの同時進行

1. キャンプが湧いたら、まずQスキルでラプター前の種を起動し、棘植物を咲かせます。
2. 植物にラプターの攻撃を受けさせながら、自分は赤バフの裏壁越しに通常攻撃を当てて赤バフを起動します。
3. 赤バフが壁を回って歩いてくる間に、ラプターは植物が自動で削り落とします。
4. 歩いてきた赤バフにQと通常攻撃を集中させ、体力を削り切ります。

この手順を狂いなくこなすと、**時計の針が2分25秒を指した時点で、森の全6キャンプが完全に消滅**します。

スカトルが湧く2分55秒に対して、実に30秒もの先行時間が生まれます。この30秒のアドバンテージが、低ランクの敵ジャングラーを完全に絶望させます。

## 3. 5分00秒のオブジェクト単独融解マニュアル

低ランクの試合では、5分ジャストにオブジェクトに触るジャングラーはほとんどいません。大半の敵はウロウロと無駄なガンクを試みて失敗し、経験値をロスしています。

そこを完全に突きます。

### ヴォイドグラブを秒殺する配置

1. 壁の裏からグラブの巣の中央にWの種を2つ落とします。
2. Qを種の上に落とし、遠距離攻撃の植物（ソーンスピッター）を咲かせます。
3. 植物が3匹のグラブの注意を引きつけるため、自分は巣の外側の安全な位置からスキルを回します。
4. スマイトを惜しまず1体目に落とし、分裂する前に処理を完了させます。

味方のTOPレーナーが押し込まれていようが、MIDがリコールしていようが関係ありません。敵がグラブの存在に気づいた頃には、3体すべてがあなたのポケットに収まっています。

### ドラゴン処理での絶対ルール

ドラゴンを一人で狩る際、唯一気をつけるべきなのはドラゴンのブレス攻撃です。ドラゴンのブレスは範囲攻撃のため、種をドラゴンの足元にまとめて置くと植物が一瞬でなぎ倒されてしまいます。

- 種はドラゴンの右斜め前と左斜め前に離して1つずつ置く。
- 1体目の植物が倒されたら、次のWを補充して咲かせる。
- 敵のボットレーンが上がってくる気配をミニマップで常に監視し、敵が寄ってきたら深追いせずEで足止めして即座に引く。

「触って、削って、ダメそうならEを置いてサッと引く」。この割り切りができるようになると、無駄なデスが完全に消えます。

## 4. 低ランクの集団戦を一人で破壊する絶対法則

ゲームが中盤に進み、ドラゴン前やバロン前で5v5のにらみ合いが始まったとき、ザイラの真の破壊力が解放されます。

低ランクの集団戦は、お互いに誰が仕掛けるかも分からず、狭い通路でウロウロと固まる時間が必ず発生します。

この「ウロウロと固まった瞬間」こそが、ザイラの即死トラップの発動ポイントです。

### 視界外からのE ➔ W ➔ W ➔ Rコンボ

集団戦で絶対にやってはいけないのは、敵の正面に姿をさらして歩いていくことです。ザイラは移動スキルを持たないため、敵のCC（行動妨害）を1つでも食らえば即座に蒸発します。

必ず、壁の向こう側やコントロールワードで視界を消した茂みの中に潜んでください。

1. 敵のキャリーや集団が狭い通路を通る瞬間に、茂みの中から**E（捕縛のツル）**を伸ばします。
2. Eのツルが飛んでいる最中に、進路上へ**Wの種を2つ素早く設置**します（これでスロウ効果を持つツタ植物が2体咲きます）。
3. スネアが当たったのを確認した瞬間、敵集団の足元全体を覆うように**R（絞殺の茨）**を展開します。
4. 最後にQを重ねてダメージを最大化します。

Rの範囲内にいる植物は巨大化し、攻撃速度が150%上昇して狂ったような継続ダメージを叩き出します。そして2秒後、巨大なツルが敵全員を宙へノックアップします。

このコンボが決まった瞬間、相手チームのHPバーは消滅し、集団戦は戦う前から終わっています。

### 敵のアサシンに飛びつかれた時の自衛ミクロ

もし敵のゼドやカ＝ジックス、アカリが視界外からあなためがけて飛び込んできたらどうするか。

焦って逃げようとして背中を見せてはいけません。逃げスキルがないザイラは、背中を向けた瞬間に死にます。

敵が飛び込んできた足元、つまり**自分の真下にEを敷き、即座に足元にWを2つ置いてQとRを叩きつけます**。

相手があなたをキルするために足を止めたその場所で、植物とノックアップの集中砲火を浴びせるのです。ゾーニャの砂時計があれば、コンボを放った直後に砂時計を使用します。相手は無敵のあなたを前に立ち尽くし、巨大化した植物に殴り倒されて返り討ちになります。

## 5. 低ランク頻出JGとの対面別攻略マニュアル

相手のジャングラーに合わせて、戦い方を少しだけ変えるだけで勝率はさらに跳ね上がります。

### vs ビエゴ / リー・シン（飛びつき系ファイター）
- **危険度**: 高（近距離でのタイマン）
- **戦術**: 川やジャングルで鉢合わせたら絶対に殴り合わない。相手がブリンクで距離を詰めてくる直線上にEを置き、スネアが入ったら植物を盾にして反対方向へ後退する。
- 相手がガンクを仕掛けてレーンに姿を見せたら、即座に反対側の敵のキャンプ（ラプターやグロンプ）に入ってすべて奪い尽くす。ファーム差で2レベルつければ、集団戦で相手は何の役にも立たなくなります。

### vs アムム / セジュアニ（タンク系ジャングラー）
- **危険度**: 低（カモ）
- **戦術**: 初手ライアンドリーの苦悶が完成した瞬間、相手のタンク性能は完全に崩壊します。植物の割合ダメージと炎上効果で、どんなに防具を積んだアムムも見る見るうちにHPが溶けていきます。
- 集団戦ではアムムの包帯（Q）の射線上にWの植物をサッと咲かせることで、包帯を植物でガードする職人技も可能です。

### vs リリア / カーサス（ファーム勝負メイジ）
- **危険度**: 中
- **戦術**: クリア速度の純粋なテンポ勝負になります。リリアも森を狩るのが速いですが、2分25秒のフルクリアを極めたザイラの方が一歩早く動けます。
- 先に川に出て視界を制圧し、相手が中立を狩っている最中に壁越しから植物を投げ込んで嫌がらせをし、リコールタイミングを狂わせます。

## 6. 勝率60.5%を叩き出した「ルーン ＆ ビルド ＆ スキル」の結論

ザイラJGの真価を引き出すには、ルーンとビルドの噛み合わせが命です。僕が129戦で導き出した結論セットを公開します。

### ルーン：メイン覇道 ✕ サブ栄華固定

メインのキーストーンは、**「試合をどう動かしたいか」によって電撃と魂の収穫を使い分ける**のが最強です。

- **メインツリー：覇道**
  - **キーストーン**:
    - **⚡ 電撃（早期決着・ガンク重視）**: 味方の序盤が強い時や、序盤から積極的にガンクや小競り合いを仕掛けて試合を畳みたい時。
    - **💀 魂の収穫（集団戦スケーリング重視）**: 低ランク特有の「試合が長引いてグダる」展開を見越し、遠距離から植物で削った敵からスタックを回収して中盤〜終盤の集団戦を破壊したい時。
  - **追い打ち**: Eのスネアや植物のスロウが入った相手に確定ダメージ。ザイラのスキルセットと完璧に噛み合います。
  - **執拗な賞金首狩り**: 非戦闘時の移動速度を底上げし、ジャングル周回・寄り・オブジェクトへの先着テンポを高速化します。
- **サブツリー：栄華（※魔道ではなく栄華固定！）**
  - **レジェンド: ヘイスト**: ジャングルキャンプの高速処理とオブジェクトの単独狩りにより、スタックが爆速で蓄積します。最大+15のスキルヘイストを最速で手に入れ、QとWの回転率が激変します。
  - **切り崩し**: 基礎HPが低いザイラは常時恩恵を受けられます。後述のライアンドリーの割合炎上と合わさり、敵のファイターやタンク前衛が驚くほどの速度で溶けます。
  *(※よくある「魔道（マナフローバンド等）」は、ジャングルアイテムの自動マナ回復があるため完全に無駄になります。栄華一択です。)*
- **ステータスシャード**: 攻撃速度（初動の森周回短縮） / アダプティブ / 伸びゆく体力

### スキル取得順：初動の安定とQ上げ

- **Lv1〜Lv3の取得**: **Lv1: Q ➔ Lv2: W ➔ Lv3: E**
- **スキル優先度**: **R ➔ Q ➔ W ➔ E**（または Q ➔ E ➔ W）
  - 基本はクリア速度とハラス火力を跳ね上げるため **Q上げ** です。Wのレベルを上げることで種のクールダウンが短縮され、森周回やオブジェクト処理での植物の維持が圧倒的に楽になります。

## 7. やると即負ける「3大やらかし」と地雷ビルド

ザイラJGを使う上で、初心者が必ずハマる3つの落とし穴があります。

### やらかし①：初手マナアイテム（ブラックファイア・トーチ等）を買う
「スキルをたくさん撃つからマナが欲しい」と、初手にブラックファイア・トーチやルーデン・コンパニオンを買ってしまう人がいます。これは完全な罠です。

ジャングル内ではジャングルアイテムのパッシブ効果により、マナは猛スピードで自動回復します。ジャングルを回る上でマナアイテムは1ミリも必要ありません。

初手は**100%「ライアンドリーの苦悶」一択**です。
ライアンドリーが持つ最大体力の割合ダメージと戦闘継続時のダメージ増加効果があって初めて、中立モンスターも敵チャンピオンも一撃で溶かせるようになります。2手目はリライ・クリスタルセプター（植物の攻撃すべてにスロウが付与され敵が逃げられなくなる）またはシャドウフレイム、3手目にゾーニャの砂時計。このビルドパスを絶対に崩さないでください。

### やらかし②：Eを適当に先撃ちして外す
ザイラのスキルの中で、自分を守れる手段はEのスネアただ一つです。
視界のないブッシュを歩く際、索敵のために適当にEを撃ち、外れた状態で歩き続けるのは自殺行為です。Eのないザイラは、ただの足の遅い歩く300ゴールドに過ぎません。

茂みの索敵は、**Wの種を放り投げるか、Qを撃って咲かせた植物に索敵させる**のが鉄則です。Eは敵の姿を捉え、確実に当たる瞬間か、飛び込まれた時のカウンター用として最後まで手元に残してください。

### やらかし③：味方のガンク要請に釣られてファームを捨てる
レーンで負けている味方ほど、「ガンクに来てくれ！」と猛烈にピンを鳴らしてきます。これに釣られて自分のジャングルキャンプを残したままレーンに向かうのは絶対にやめてください。

低ランクの負けているレーンにガンクに行っても、味方が合わせられずにカウンターガンクを食らってダブルキルを渡すのが関の山です。
味方のピンはミュートし、**自分のキャンプをすべて狩り尽くしてレベル先行すること**を最優先してください。あなたがレベルとアイテムで敵JGを引き離し、ドラゴンとグラブを一人で集めて中盤の集団戦を破壊すれば、試合は勝手に勝ちます。
