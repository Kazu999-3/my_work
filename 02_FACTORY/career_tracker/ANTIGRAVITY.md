# 転職管理トラッカー (Career Tracker) 憲法

## 👑 プロジェクト概要
転職活動における応募企業、選考進捗、条件（月収・勤務形態・志望度）、求人情報URL、次回アクション期日を一元管理するローカル完結型Webアプリケーション。

## 🎯 目的・ターゲット・利用シーン
- **目的**: 複数エージェント・媒体にまたがる応募状況の把握、期日漏れ防止、条件比較の最適化。
- **ターゲット**: 個人利用（転職活動者）。
- **利用シーン**: PCブラウザ上で日常的に進捗更新、面接前後のメモ確認、優先度検討。

## 🏛️ 技術スタック
- **Frontend**: Single File HTML5 / CSS3 (Notion・スプレッドシート風インライン編集UI) / Vanilla JavaScript (ES6+)
- **Storage**: ブラウザ LocalStorage（完全ローカル完結、自動保存インジケーター付き）
- **Backup**: JSONエクスポート / インポート機能

## 📦 管理データスキーマ
| フィールド | 型 | 必須 | 説明 |
| :--- | :--- | :--- | :--- |
| `id` | string (UUID) | ○ | 一意識別子 |
| `company_name` | string | ○ | 企業名 |
| `job_title` | string | - | 応募職種（例: フロントエンドエンジニア、法人営業など） |
| `status` | string | ○ | 書類準備 / 応募済 / 書類通過 / 1次面接 / 2次面接 / 最終面接 / 内定 / 見送り / 辞退 |
| `source` | string | ○ | マイナビ転職 / エン転職 / リクナビNEXT / doda / indeed / その他 |
| `salary` | number | - | 想定・提示月収（万円） |
| `work_style` | string | ○ | フルリモート / ハイブリッド / 出社 |
| `priority` | number (1-5) | ○ | 志望度（★1〜★5） |
| `next_action_date` | string (YYYY-MM-DD) | - | 次回選考日 / 提出期日 |
| `attraction` | string | - | 魅力・惹かれたポイント・志望動機メモ |
| `job_url` | string | - | 求人詳細URL |
| `created_at` | string (ISO) | ○ | 作成日時 |
| `updated_at` | string (ISO) | ○ | 更新日時 |

## 🚀 MVP（最小構成）の範囲
1. **スプレッドシート型インライン編集**: 一覧テーブル上で全項目をダイレクト入力・変更（ポップアップ廃止）。
2. **クイック行追加**: 「＋ 新規行を追加」で最上行に即座に新規入力行を挿入＆社名へオートフォーカス。
3. **リアルタイム自動保存**: 入力・変更時にLocalStorageへ即座に自動保存（「✓ 自動保存完了」フィードバック）。
4. **ソート機能**: 志望度、月収（高/低）、次回期日（昇順）、更新順、社名順。
5. **フィルター＆検索**: 状況別、媒体別、勤務形態別絞り込み、およびフリーワード検索。
6. **クイック集計**: 応募総数、選考中件数、内定数、選考中平均月収（想定年収換算）、直近期日アラート。
7. **データ保護**: LocalStorage保存、JSONバックアップ・リストア。
