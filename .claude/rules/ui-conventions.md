# UI デザインシステム ＆ 表現規約

## 1. 確定カラーパレット（やわらかい暖色ダーク ＆ Hextech調）
「サイバーパンク調のネオン青・紫」から「やわらかい暖色ダーク」へのデザイン統一は **2026-09-30に完了**しました（それ以前は「統一済み」と書かれていましたが、実際には `04_PORTAL/src` に禁止色が1,286箇所残っていました）。新規コンポーネント・UI作成時はこのパレットを厳守してください。

- **サイバーパンク・派手なネオングローの禁止**:
  - 寒色系ネオン（blue/indigo/purple/cyanの発光や派手なborder-glow）は原則禁止。
- **統一時に使った置換ルール**（新規実装で寒色を使いたくなった時も同じ判断で置き換える）:
  - `blue` / `sky` / `cyan` → **`teal`**（ヘクステックブルー `#0AC8B9` 相当。下記セカンダリとして許可されている寒色）
  - `indigo` / `purple` / `violet` / `fuchsia` → **`amber`**（Hextechゴールド）
  - 番台（`-100` `-500` 等）は変えない。コントラストと視覚的階層をそのまま保つため。
  - ⚠️ **色で「データの種類」を区別している箇所は機械的に置換しないこと。**
    2026-09-30の統一時、ランク階級（`lib/mmr.ts`）・師弟コースの期間バッジ・チャンピオンの
    アーキタイプバッジで、元は別の色相だったものが同じ色に寄って**見分けがつかなくなった**。
    こうしたマッピングは許可パレット内で番台を振り分けて区別を維持する。
- **明示的な例外**: `04_PORTAL/src/lib/mmr.ts` のランク階級色（Diamond=青 / Master=紫 /
  Challenger=空色）は LoL公式の階級色をそのまま使う。装飾ではなくプレイヤーが読む意味のある
  データで、Diamondを金色にすると情報として誤りになるため。発光は使わず淡い塗りのみ。
- **ベースカラー**:
  - **背景**: やわらかい暖色ダーク（`#2b2620`、Tailwind `stone-900` / `stone-950` 系）。漆黒（`#000000`）は避ける。
  - **カード/パネル背景**: `stone-800/80`、`stone-900/60`（半透明ブラー推奨）。
  - **テキスト**: `stone-100`（主テキスト）、`stone-400`（補足テキスト・ラベル）。
  - **ボーダー**: `stone-700/60`、`stone-800`。
- **アクセントカラー (LoL Hextech 調)**:
  - **プライマリ**: Hextechゴールド（`#C89B3C`、Tailwind `amber-500` / `amber-400`）。
  - **セカンダリ**: 深淵スレート（`#091428`）、ヘクステックブルー（`#0AC8B9`）。
  - **成功通知**: エメラルドグリーン（`bg-emerald-950/30 text-emerald-400 border-emerald-800/60`）。琥珀色（警告色）を成功メッセージに使わないこと。
  - **警告・エラー**: ローズ（`bg-rose-950/30 text-rose-400 border-rose-800/60`）。

## 2. レスポンシブ ＆ モバイル対応
- ヘッダー、テーブル、タブナビゲーションは、スマートフォン画面（幅375px〜）でも文字やボタンが見切れないよう、適切な折り返し（`flex-wrap`）または横スクロール（`overflow-x-auto`）を必ず設定すること。
