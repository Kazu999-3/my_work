# UI デザインシステム ＆ 表現規約

## 1. 確定カラーパレット（やわらかい暖色ダーク ＆ Hextech調）
過去のセッションで「サイバーパンク調のネオン青・紫」から「やわらかい暖色ダーク」へデザイン統一済みです。新規コンポーネント・UI作成時はこのパレットを厳守してください。

- **サイバーパンク・派手なネオングローの禁止**:
  - 寒色系ネオン（blue/indigo/purple/cyanの発光や派手なborder-glow）は原則禁止。
- **ベースカラー**:
  - **背景**: やわらかい暖色ダーク（`#2b2620`、Tailwind `stone-900` / `stone-950` 系）。漆黒（`#000000`）は避ける。
  - **カード/パネル背景**: `stone-800/80`、`stone-900/60`（半透明ブラー推奨）。
  - **テキスト**: `stone-100`（主テキスト）、`stone-400`（補足テキスト・ラベル）。
  - **ボーダー**: `stone-700/60`、`stone-800`。
- **アクセントカラー (LoL Hextech 調)**:
  - **プライマリ**: Hextechゴールド（`#C89B3C`、Tailwind `amber-500` / `amber-400`）。
  - **セカンダリ**: 深淵スレート（`#091428`）、ヘクステックブルー（`#0AC8B9`）。
  - **成功通知**: エメラルドグリーン（`bg-emerald-950/30 text-emerald-400 border-emerald-800/60`）。琥珀色（警告色）を成功メッセージに使わないこと。
  - **警告・エラー**: ローズ（`bg-rose-950/30 text-rose-400 border-rose-800/60`）。

## 2. レスポンシブ ＆ モバイル対応
- ヘッダー、テーブル、タブナビゲーションは、スマートフォン画面（幅375px〜）でも文字やボタンが見切れないよう、適切な折り返し（`flex-wrap`）または横スクロール（`overflow-x-auto`）を必ず設定すること。
