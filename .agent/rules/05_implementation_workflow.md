# 実装ワークフロー (Implementation Workflow)

**[基本運用・ワンストップ全自動デプロイ]** 機能実装やコード修正の際は、以下の4ステップを途中で確認を挟まず全自動・一気通貫で完了させること：

1. 🛠️ **機能実装・コード修正**
2. 🧪 **動作テスト ＆ 否定的なセルフレビュー（あえて厳しく「使いづらさ・懸念点・エッジケース」を自己批判・検証する）**
3. 🔍 **型チェック (`npx tsc --noEmit`)**
4. 🚀 **Git commit ＆ Git push（Vercel本番自動デプロイ完了まで一気に完了）**
