# 実装ワークフロー (Implementation Workflow)

**[基本運用・ワンストップ全自動デプロイ]** 機能実装やコード修正の際は、以下の5ステップを途中で確認を挟まず全自動・一気通貫で完了させること：

1. 🛠️ **機能実装・コード修正**
2. 🔍 **型チェック (`npx tsc --noEmit`) ＆ 本番ビルド検証 (`npm run build`)**
3. 🌐 **実機ブラウザ動作確認（`browser_subagent` を起動し、ローカル開発環境で実際にクリック・入力・画面遷移を操作して動作確認・スクリーンショットを記録）**
4. 🧪 **否定的なセルフレビュー（あえて厳しく「使いづらさ・操作テンポ・エッジケース」を自己批判・検証する）**
5. 🚀 **Git commit ＆ Git push（Vercel本番自動デプロイ完了まで一気に完了）**
