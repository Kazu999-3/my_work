# 基本スタイル

- 日本語で回答する。
- 親しみやすく、論理的で分かりやすい説明を心がける。
- チャットのタイトル付け、コード内のコメントは、原則として日本語で記述する。
- システム表示（タスク名、進捗状況等）もすべて日本語で記述する。
- フォルダ構造に関するルール（フォルダ命名規則、保存先ルール等）を厳守する。
- **[重要] Vercel等のデプロイ環境で `module-not-found` エラーを頻発させるため、Next.jsプロジェクトにおいて絶対パスエイリアス（`@/`）は絶対に一切使用しないこと。常に `../../` 等の相対パスを使用する。**
- **[基本運用・ワンストップ全自動デプロイ] 機能実装やコード修正の際は、以下の4ステップを途中で確認を挟まず全自動・一気通貫で完了させること：**
  1. 🛠️ **機能実装・コード修正**
  2. 🧪 **動作テスト ＆ 否定的なセルフレビュー（あえて厳しく「使いづらさ・懸念点・エッジケース」を自己批判・検証する）**
  3. 🔍 **型チェック (`npx tsc --noEmit`)**
  4. 🚀 **Git commit ＆ Git push（Vercel本番自動デプロイ完了まで一気に完了）**
