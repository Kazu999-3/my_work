# ハルシネーション防止 ＆ 知識カットオフ対策規約

## 1. 存在しない型・関数の捏造防止 (Anti-Hallucination)
- Gemini 3 は超大容量コンテキストと高い推論能力を持つ反面、コードベースのインデックスを直接参照していない場合、**存在しない型定義や関数を推論で補おうとして捏造するリスク**がある。
- **必須手順**:
  - 関数やコンポーネントを呼び出す前は、必ず `view_file` や `grep_search` を用いて、実際の型定義や引数の構造を 100% 確認してからコードを書き換えること。
  - 推測や過去の記憶だけで `interface` や `props` を更新してはならない。

## 2. 知識カットオフ（最新情報のファクトチェック）
- 特定のパッチバージョン（例: LoL パッチ 26.15 以降。表記は西暦下2桁基準の26.xxで統一）や、最新の外部ライブラリ仕様を扱う際は、AI自身の学習データ（過去の記憶）を過信してはならない。
- **必須手順**:
  - 必ず `search_web` またはローカルSSOT DB (`champion_facts`) を参照して最新のコンテキストを取得してから回答・コード生成を行うこと。
  - 勝手に過去のパッチや過去の仕様へ読み替えないこと。

## 3. ダミーデータ・モックフォールバックの禁止（実データ厳守原則）
- **最上位命令**: ユーザーから「テスト用にモックを作って」等の明確・意図的な指示があった場合を除き、**ポータルのすべての機能・API・UIにおいてダミーデータ、モックデータ、ハードコードされた架空の戦績・レビューを載せてはならない**。
- **必須手順**:
  - API通信失敗時やデータ未取得時は、ダミーデータを捏造して正常に見せかけるのではなく、**正確なエラーメッセージ（「〇〇が見つかりませんでした」等）または明確な空状態（Empty State）を表示**すること。
  - 特定プレイヤー（Kazurin等）のデータをデフォルトフォールバックとして他のプレイヤーへ流用・表示する行為を厳禁とする。
