# 🏁 セッション終了 全自動ラップアップ (/wrap-up)

> **Coupen原則**: 作業が終わった時点で満足するので、人間は日誌を書かない。
> AIに書かせ、翌日のセッションでAI自身が真っ先に読み直す立ち上がり循環を維持する。

ユーザーから「`/wrap-up`」または「お疲れ様」「今日の作業終了」と伝えられた際、AIは以下のステップを**途中で確認を挟まず自律的に一括実行**します。

---

## 🚀 自律実行ステップ (Steps 1-5)

### ステップ1: 本日の作業経緯 ＆ 没理由の抽出
1. 本セッション中の会話ログおよび `git diff` を走査する。
2. 「今日何を作ったか（達成事項）」を箇条書きで整理する。
3. 議論の中で「なぜその設計にしたか」「どの選択肢をなぜ落としたか（没理由）」を抽出する。

### ステップ2: 再利用可能な3行ナレッジの自動抽出
1. 本日の作業やデバッグ、調査から得られた**「他でも使える知見・教訓」をちょうど3行**抽出する。

### ステップ3: `DAILY_LOG.md` への自動追記
1. `d:/my_work/02_FACTORY/DAILY_LOG.md` を読み込む。
2. 今日の日付エントリ（存在しない場合は新規作成）の末尾に、上記ステップ1・2の成果を制式フォーマットで追記する。

### ステップ4: `TODO.md` のタスク完了同期
1. `d:/my_work/02_FACTORY/TODO.md` を読み込む。
2. 本日完了したタスクのチェックボックスを `- [x]` に更新し、セッション実績セクションへ追記する。

### ステップ5: セキュリティ監査 ＆ Git Commit & Push
1. 機密ガードスクリプトを実行し、APIキーや秘密情報の混入がないかチェック：
   ```powershell
   py d:\my_work\scripts\pre_commit_guard.py
   ```
2. 変更ファイルをステージングし、日本語コミットメッセージを作成してコミット。
3. リモートリポジトリへプッシュ：
   ```powershell
   git push origin master
   ```
4. ユーザーへ「本日の作業完了サマリー」と「明日やるべき次の一歩」を提示して終了する。
