# プロンプト技法チェックリスト

AIへの依頼と回答の質を上げるための18技法。全部を毎回使うのではなく、場面に合わせて必要なものだけを選んで適用する。各技法は「AIへの指示例」としてそのまま依頼文や追加指示に差し込める。

## 1. 依頼する前（依頼文の点検）

- **前提検証**：「そもそも質問の立て方が正しいか検証して」— 依頼の前提自体がずれていないか、解くべき問題が本当にそれかを確認する
- **条件明確化**：「回答に必要な情報が揃うまで確認して」— 情報不足のまま回答させず、不足分を質問として返させる
- **質問文の書き直し**：「この目的を達成する最強の質問文に書き直して」— 依頼文を出す前に、目的に対して最適な形へ推敲する
- **評価基準を先に決める**：「回答前に評価基準を決めて」— 良し悪しの物差しを先に置き、回答の品質を安定させる
- **最重要論点の特定**：「最も重要な論点を特定して」— 依頼の中心論点を1つに絞り、回答の焦点をぼかさない
- **見落とし条件の洗い出し**：「見落としがちな条件を洗い出して」— 依頼文に書いていない暗黙の条件・制約を先に表面化する

## 2. 回答を受け取った後（回答の点検）

- **弱点を3つ挙げる**：「この回答の弱点を3つ挙げて」— 回答の精度改善のため、弱い箇所を具体的に指摘させる
- **成立しない条件探し**：「この結論が成立しない条件を探して」— 結論が崩れるケースを先に洗い出し、誤判断を防ぐ
- **自己レビュー**：「最初の回答を批判的に検証して」— 回答者自身に批判的な再検証をさせ、誤りや飛躍を正す
- **80点と仮定して改善**：「回答を80点と仮定して改善して」— 現状を80点と置き、残り20点分の改善点を実行させる
- **根拠と不確実性の分離**：「回答の根拠と不確実な部分を分けて」— 確かな部分と曖昧な部分を分け、信頼できる範囲を明確にする
- **採点**：「判断基準を作って回答を採点して」— 基準を明文化した上で採点し、品質を目に見える形にする
- **優先順位づけ**：「実行難易度と効果で優先順位をつけて」— 回答中の提案・タスクを難易度と効果で並べ替え、着手順を決める

## 3. 深掘り（一段深い回答を引き出す）

- **専門家の視点でレビュー**：「専門家の視点でレビューして」— 実務家の目で回答を再点検し、質を引き上げる
- **反対意見を踏まえて再回答**：「反対意見を踏まえて再回答して」— あえて反対の立場をぶつけ、反論を織り込んだ回答に更新させる
- **別の切り口で最適解3つ**：「別の切り口から最適解を3つ出して」— 最初の解に固執させず、視野を広げて候補を増やす
- **一流の専門家の追加調査**：「一流の専門家なら何を追加で調べるか」— プロなら次に調べる項目を挙げさせ、深掘りの方向を決める
- **理想解と次善策**：「理想解と現実的な次善策を提示して」— 理想と、現実に実行できる次善策の両方を出させ、実行力を確保する

## 使い方の目安

- SPEC・指示文の作成時：まず「1. 依頼する前」の前提検証・条件明確化・質問文の書き直しを通し、未決事項や暗黙の条件を潰してから出す
- 調査・レビュー結果の受け取り時：「2. 回答を受け取った後」の弱点3つ・成立しない条件探し・根拠と不確実性の分離で裏を取り、重要なものは採点まで行う
- 判断に迷うとき・質をもう一段上げたいとき：「3. 深掘り」の反対意見・別の切り口3つ・理想解と次善策で視野を広げてから決める
