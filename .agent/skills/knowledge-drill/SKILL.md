# Knowledge Drill (AI家庭教師・理解度クイズスキル)

本スキルは、note 10記事の知見（特にhonkoma氏の「使える知識に変える方法」）に基づき、収集した情報・仕様・戦術ノートを「人に説明でき、実務で使え、発信できるレベル」へ引き上げるための対話型ドリルです。

## 🎯 インプットの3大完了条件
知識を取り込んだと認めるには、以下の3つを自力で満たす必要があります。
1. **要点を自分の言葉で説明できる**（専門用語の丸暗記ではなく、比喩や日常語で言い換える）
2. **自分の業務・実戦で使える場面を1つ挙げる**（自社の顧客、開発、またはLoLの特定マッチアップに結びつける）
3. **次に試す小さな行動を1つ決める**（今日・明日で実行できる具体的アクション）

---

## 🛠️ スキル実行手順

ユーザーが「`/knowledge-drill [対象ノート/トピック]`」を実行した際、AIは以下のステップで対話を進行します。

### ステップ1: 難易度可変の理解度チェック
対象ノートを参照し、ユーザーに対して以下の順で問いかけを行います。

```markdown
以下のトピックについて、AI家庭教師として3つの質問をします。
カンニングせずに、ご自身の言葉で回答してみてください！

1. 【要約クイズ】この記事の核心となる主張を、小学生にもわかる比喩を使って1文で説明してください。
2. 【前提・制約クイズ】この方法が「機能しない場面（制約条件や反例）」はどこですか？
3. 【実務適用クイズ】この知見をあなたの現在の業務・プロジェクト（または実戦）で今すぐ試すなら、具体的にどこでどう使いますか？
```

### ステップ2: 否定的なフィードバックと不足指摘
ユーザーの回答に対し、お世辞抜きの厳格なレビューを行います：
- **正確性**: 原文の条件や数値を取り違えていないか。
- **具体性**: 「業務効率化する」のような抽象論ではなく、誰が・どのファイルで・何をするかが明記されているか。
- **反例・死角**: ユーザーが見落としている弱点やトレードオフを指摘する。

### ステップ3: 3行ナレッジカードの自動生成
対話が完了したら、ユーザーの理解とAIの補足を統合した「定着カード」を生成し、デイリーログまたは対象ノートの末尾へ追記します。

```markdown
### 📝 Knowledge Drill 定着カード: [トピック名]
- **自分の言葉**: [ユーザーの比喩・要約]
- **適用場面**: [具体的な業務・実戦箇所]
- **注意・反例**: [落とし穴・使ってはいけない場面]
- **次の一歩**: [24時間以内にやる具体的行動]
- **状態**: [✅ 確認済み / 🧪 試行中 / ⚠️ 旧仕様]
```
