# Discord 告知・募集文ジェネレーター (bot-copy-generator)

このスキルは、League of Legends (LoL) コミュニティやカスタムマッチ運営において、参加者が集まりやすく、心理的抵抗の少ない募集文面を自動生成するためのスキルです。

## 🎯 運用の最上位原則

1. **広告調・AI臭い社交辞令の【完全排除】**:
   - ❌ 禁止ワード: 「実力均等化」「ボリュームゾーン」「お楽しみいただけます✨」「安心の仕組み」「盛り上がりましょう」「豪華景品」「〜となっております」
   - ⭕ 推奨表現: 「チームの実力を五分五分に分ける」「同じレベル同士で楽しむ」「遠慮せず押して」「〜です」「〜します」
2. **中学生にもストレートに伝わる日常会話の言葉**:
   - 難しい専門用語や運営目線の言葉を使わず、読んだ瞬間に状況がわかる平易な言葉にする。
3. **初心者の不安を冒頭で一掃する**:
   - 参加をためらう最大の理由は「自分が下手で迷惑をかけるのではないか」という恐怖。
   - 冒頭に「🔰 低ランクだけど迷惑かけない？ ➔ まったく気にせず押してください！」を配置し、人数が集まること自体が全員のメリット（同レベル部屋の成立）になる構造を伝える。
4. **時間を断定せず濁す（アドリブ運営への配慮）**:
   - ❌ 禁止: 「23:30終了」「3試合行います」
   - ⭕ 推奨: 「24時前後目安」「3戦程度」「本戦終了まで（メイヘムは自由参加）」
5. **Embed外のチャット本文（content）として最適化**:
   - Embedの文字数制限（1024文字）に頼らず、チャット本文として改行と箇条書きで見やすくレイアウトする。

## 📋 テンプレート構造

```markdown
@カスタム通知役
📢 **【[曜日/イベント名] 定期カスタム募集】**

🔰 **「低ランクだけど迷惑かけない…？」**
➔ **まったく気にせず押してください！**
人数が集まるほど、同じレベル同士で対戦しやすくなります。
（20人集まれば「強い人部屋」「初中級部屋」の2部屋開催！ 1部屋でもチーム戦力が五分五分になるよう自動調整されます）

---

🗓️ **開催日時**: [開催日] 21:00〜（24:00前後目安）
🎮 **試合形式**: 3戦程度（本戦終了後、希望者のみ自由参加でお祭りメイヘム1戦）
📍 **参加方法**: 下のカードのボタンを押すだけ！

---

[曜日ごとの補足（土曜は同実力対決、日曜は特殊ルール・自由ピックのお祭りなど）]
```

---

## 🛠️ 出力手順

1. ユーザーから「開催日時」「曜日」「特記事項（特殊ルール等）」を受け取る。
2. 上記原則に基づき、修正なしでそのままDiscordへコピペできるテキストを生成する。
3. 文字数がDiscordメッセージ上限（2,000文字）に対して快適な範囲（400〜800文字）に収まっていることを確認する。
