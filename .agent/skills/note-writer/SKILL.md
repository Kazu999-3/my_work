# note 500円記事自動ライティングスキル (note_writer)

## 🎯 目的
`champion_facts` テーブルの正本データ（SSOT）を読み込み、読者がすぐに購入・実践したくなる500円モデルの有料note記事およびX(Twitter)宣伝テキストを自動生成します。

## 📜 執筆原則
1. **AI臭いポエムの絶対排除**:
   - 「王」「軍師」「圧倒的な力」「至高の」「絶対的な支配者」などの抽象的でポエミーな装飾表現は一切使用しないこと。
2. **構成**:
   - **タイトル (32文字以内)**: 「なぜ今パッチでこのチャンピオンを使うと勝てるのか」の強いフック。
   - **無料部分 (約400文字)**: 読者のSoloQでの悩みに共感 ➔ パッチでの勝率根拠 ➔ 購入のメリット。
   - **有料部分 (約800文字)**: コアビルドの購入順序、ルーン理由、〜10分/〜20分の具体的立ち回り、対面対策。
   - **X宣伝テキスト (140文字以内)**: クリック率を高める疑問提示とリンク用フック。
