# 💵 アフィリエイト収益化SPAコントロール

> **⚠️ 現在停止中（2026-07-26）**: 旧・収益化パイプライン（`_MONETIZE/` 一式、自動記事生成バッチ、A/Bテスト・GA最適化、ノート下書き自動投稿など）は、設計を見直した上で改めて実装するため、一旦削除されました。以下は削除前の旧仕様の記録です。

## 削除された旧機能の概要（記録）

IT自動アフィリエイト運用のアクセス分析、案件リンクの編集、自動記事生成バッチ（ドライラン/本番）の監視コンソールなどを一元管理する管理者用のSPA（Single Page Application）機能でした。

*   **データソース（取得元）**:
    *   Supabase `note_pv_history` テーブル（PV、Likes、Comments数などのnoteアクセス履歴）。
    *   ローカルファイル `02_FACTORY/affiliate_links.json` (アフィリエイトリンクの一覧)。
    *   ローカルファイル `02_FACTORY/affiliate_knowledge.md` (副業運用メモ)。
*   **旧・自動処理フロー**: トレンド収集 → AIによる記事自動生成 → note下書き自動保存 ＆ Xスレッド自動投稿（Playwright）→ アクセス分析による自己進化（GA最適化）。

再実装する際は、上記の設計をベースにしつつ、`PUBLISH_DISABLED` の既定値やダミーデータのフォールバックなど、旧実装で見つかった問題点を踏まえて設計し直すこと。
