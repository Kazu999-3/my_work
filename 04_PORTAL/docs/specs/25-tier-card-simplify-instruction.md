# 指示文25: プロフィールの「格上との関わり方」カードを2つの質問に単純化する

作成: 2026-11-22（Muse）
対象: 04_PORTAL（プロフィール設定画面 PlayerSettingsPanel の「⚔️ 格上との関わり方」カード）
経緯: SPEC 18 v4 で導入した2軸マス目（縦：対面／横：上の帯）は、実物を見たユーザーから「分かりにくい」との指摘（2026-11-22）。中身は2つの独立した質問なのに、マスの繰り返し文言と「縦軸・横軸」の説明で難しく見えている。また、上位帯のメンバーには「上の帯への繰り上げ」の質問自体が対象外なのに、効かない選択肢が並んでいる。

## やること

- [ ] 2軸マス目をやめ、**2つの質問を縦に並べる**形に変える。各質問は「質問文＋選択肢（ラジオ式）＋各選択肢の短い説明」で構成する。
  - 質問1（対面）：「同じ試合で、実力が上の人と対面（縦レーンの相手）になるのを避けたいですか？」
    - 選択肢は現行どおり2つ：「格上対面を避ける（別レーンに回す）」／「格上対面もOK」。保存先は既存の `allow_higher` のまま。
  - 質問2（帯の繰り上げ）：「上の帯の試合に混ざって参加しますか？」
    - 選択肢は現行どおり3つ：「混ざってもいい」／「人不足ならOK（既定）」／「自分の帯のみ」。保存先は既存の `tier_promotion_pref` のまま。
- [ ] **上位帯（MMR 1450+）のメンバーには、質問2を無効表示**にし、「上位帯の方は対象外です（上に上がる帯がありません）」という趣旨の注記を付ける（選択は変えられないが、保存済みの値自体は消さない）。
- [ ] カード冒頭の説明文から「縦軸・横軸」等の言い回しをなくし、平易な文にする。帯分け（Portal MMR 1450で上位帯／中初級帯）の説明は残してよいが、短くする。
- [ ] 「今のあなたの設定」の要約表示は、2つの質問への回答が両方とも分かる形を維持する。

## やらないこと
- 保存する値・項目・DBの変更（既存の `allow_higher` / `tier_promotion_pref` とその値の意味は一切変えない。見た目と文言だけの変更）。
- レーン希望カード・その他の設定カードの変更。
- バランサー側の帯分け・繰り上げロジックの変更。

## 完了条件
- ローカルで `npm run build` が成功してから push すること。
- 上位帯アカウントと中初級帯アカウントの両方で表示を確認し、結果を報告すること（上位帯では質問2が無効表示＋注記になること、中初級帯では両方の質問に答えられること）。

## 未決事項
- なし。判断が必要な点が出たら、決めずに報告すること。
