# SPEC 11：当日のカスタム勝率を確認できる機能

## 目的
カスタム開催日に、その日の自分の（または参加者の）調子をその場で確認できるようにする。ポータルで「当日のカスタムだけ」の勝率が見られるようにする。

## 決定済み（2026-11-22 ユーザー）
- 表示場所は **バランサー画面** とする。

## やること
- [ ] 対戦履歴データから、当日（JST）のカスタム試合だけを集計する
- [ ] バランサー画面に、当日分の 試合数・勝ち数・勝率 を表示する
- [ ] 日付が変わったら自動で当日分に切り替わる（手動の期間指定は対象外）

## やらないこと
- 過去日の勝率集計や期間指定の分析機能（それは対戦履歴の既存フィルターの範囲）
- MMR・バランサーへの影響（表示のみの機能）

## 完了条件
- 開催日の夜に開くと、その日のカスタムの試合数・勝ち数・勝率が正しく表示される
- ローカルで `npm run build`（04_PORTAL）が成功してからプッシュする

## 未決事項（エージェントが勝手に決めない）
1. 表示対象：自分の分だけか、参加者全員の一覧か
2. 集計対象：定期カスタムのみか、大会を含む全カスタムか
3. 「当日」の区切り：JST 0:00 起点でよいか（深夜開催の扱い）
