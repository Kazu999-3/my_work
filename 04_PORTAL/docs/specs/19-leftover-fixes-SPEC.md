## 目的

## 現状の問題（2026-11-22 確認）
1. サイドバーのユーザーカードの残高だけ「18,647 pt」と表示され、他の画面の「コイン」と食い違う（本番確認済み）。SPEC 14 で通貨は「コイン」に統一されたはずの漏れ。
2. 新規 API `GET /api/balancer/today-stats` に認証チェックがなく、未ログインでも当日参加者全員の勝敗・勝率が取得できる。
3. サイドバーの管理者セクションの内容が、画面遷移の途中で変わる（最初は「管理者ダッシュボード／バランサー設定／コイン管理／リプレイ道筋マップ」の4件、途中から「管理画面／リプレイ道筋マップ／LoLディープアナライザー」の3件）。本番で再現を確認したが原因は未特定。
4. SPEC 17（狭幅対応14件）はコード対応済みだが、SPEC 自身の完了条件だった「修正後に375px相当で全対象を確認」が未実施（実装側も DAILY_LOG で `[要検証]` と明記）。
