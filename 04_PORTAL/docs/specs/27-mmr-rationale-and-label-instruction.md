# 指示文27: SPEC 10の値の根拠の記載と「推定MMRランク」表記への書き換え

作成: 2026-11-22（Muse）
対象: 04_PORTAL
経緯: SPEC 10（帯分け）で Antigravity が自己決定した値（2帯制・境目 MMR 1450・繰り上げ3択のデフォルト等）について、ユーザーが 2026-11-22 に「このままでいい」と採用を決定。そのうえで2つの追加要望があった。

## やること

- [ ] **根拠の記載**：採用した各値の根拠を、関連ドキュメント（`04_PORTAL/docs/specs/10-tier-band-custom-SPEC.md` への追記、または同フォルダの補足ドキュメント）に明記する。特に境目 MMR 1450 については、根拠となった実測の MMR 分布（対象人数・分布の概要など、決定時に見た実データ）を書くこと。他の値（2帯にした理由、繰り上げ優先順位、オフレーン2段階ルール）も、決めた理由を1〜2行ずつ書く。
- [ ] **表記の書き換え**：画面上で MMR や帯を示している表示文言の呼び方を「**推定MMRランク**」にそろえる（プロフィールの「現在の帯」表示、バランサー、リーダーボードなど、ユーザーが目にする箇所）。Portal の MMR は内部の推定値であることが伝わる呼び方にするのが目的。

## やらないこと
- 値そのものの変更（2帯・MMR 1450・3択デフォルト等はユーザーが採用済み。そのまま）。
- MMR の計算方法・バランサーのロジックの変更。内部の変数名・コード上の識別子の変更も対象外（対象はユーザー向けの表示文言とドキュメントのみ）。

## 完了条件
- ローカルで `npm run build` が成功してから push すること。
- 根拠を書いたドキュメントの場所と、書き換えた表示箇所の一覧を報告すること。
