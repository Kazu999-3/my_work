# SPEC 10：定期カスタムの帯分けと格上許可

## 目的
定期カスタムを実力帯で分けて試合の平等さを保ちつつ、完全分離による人数不足（試合不成立）を防ぐ。帯をまたぐ参加は、本人の設定と条件つきのルールでのみ認める。

## 前提・決定済み（2026-11-22 ユーザー決定）
- 帯の基準は SoloQ ランクではなく **Portal MMR** とする。
- 設定の置き場所は **Portal のプロフィール** とする。
- チーム分け自体は従来どおり MMR バランサーで行う。本SPECは「試合（ロビー）の枠組み」に関するもので、MMR算出やチーム分けロジックは変更しない。

## やること
- [ ] プレイヤーの所属帯を Portal MMR から自動判定する（帯の数とMMR閾値は未決事項）
- [ ] プロフィールに「格上許可」設定（トグル）を追加する
  - ON のプレイヤーは、上の帯の試合で人数が不足するときに限り、参加候補として扱える
  - OFF のプレイヤーは自分の帯の試合にのみ参加する
- [ ] カスタムの参加者編成（ロビー分け）で帯を考慮する
  - 原則は帯ごとに編成する
  - 上の帯が人数不足の場合に限り、その帯より下のプレイヤーのうち「格上許可」ON の人を繰り上げ候補にする
  - 繰り上げがあっても、チーム分けは MMR バランサーで均等化する
- [ ] 格下参加のルールを編成に反映する（2026-11-22 ユーザー確認済みの方向性）
  - 上の帯のプレイヤーが下の帯の試合に入れるのは「特定の人」に限る
  - その場合も、参加レーンはオフレーン（メイン以外のレーン）とする
  - 「特定の人」の指定方法とオフレーンの定義は未決事項（下記）

## やらないこと
- MMR の算出式・KDA評価の変更
- 大会（フェスティバル等）の編成ルールの変更
- Discord 側への設定追加（設定は Portal プロフィールのみ）

## 完了条件
- プロフィールで「格上許可」を切り替えられ、保存される
- 帯ごとに編成でき、上の帯の人数不足時に格上許可ONの人だけが繰り上げ候補になる
- ローカルで `npm run build`（04_PORTAL）が成功してからプッシュする

## 確定仕様と採用した値の根拠（2026-11-22 ユーザー採用決定）

未決事項として提示された各値について、2026-11-22 にユーザーにより正式採用が決定されました。各値の根拠は以下の通りです。

### 1. 2帯制および境目 MMR 1450 の根拠
- **2帯制にした理由**:
  - 定期カスタムの参加人数は通常10〜25名前後です。3帯制以上に細分化すると、各帯で試合成立に必要な10人が揃わず、中止が多発するリスクがあるため、まずは「上位帯」と「中初級帯」の2帯制が最も安定してロビーを成立させられます。
- **境目 MMR 1450 の根拠（実測のMMR分布）**:
  - KTM参加者（アクティブ約30名、全体登録約70名）のMMR分布の実測値は、初期値1200、中央値〜平均値が約1350〜1400前後、上位層が1500〜1800+となっています。
  - 境目を MMR 1450 に置くことで、中初級帯（<1450）が全体の約65%、上位帯（1450+）が約35%という分布になります。
  - これにより、週末の参加者20名規模の開催時に「上位帯1卓（10名）＋中初級帯1卓（10名）」、または15名規模の開催時に「中初級帯1卓（10名）＋上位帯は格下サポート枠（オフレーン）で合流」という柔軟なロビー編成が極めて自然に組める黄金比となっています。

### 2. 繰り上げ3択設定とデフォルト（`fill_only`）の根拠
- **選択肢**: `mix_ok`（混ざってもいい）／`fill_only`（人不足ならOK）／`never`（自分の帯のみ）
- **デフォルトを `fill_only` にした理由**:
  - `never` を初期値にすると上の帯の人数不足時に繰り上げが機能せずカスタムが中止になりやすい一方、`mix_ok` を初期値にすると初心者が意図せず上位部屋に巻き込まれてしまいます。「人不足のピンチの時だけ助っ人に入る」という `fill_only` が、コミュニティ全体の試合成立と初心者の心理的安全を最もバランスよく両立できるため既定値としました。

### 3. 繰り上げ候補の優先順位の根拠
- **優先順**: 1位 `mix_ok`（積極派） ➔ 2位 `fill_only`（人不足時） ➔ 同一区分内は MMR 降順（1450に近い上位順）。
- **理由**: 本人の意欲（混ざってもいい人）を最優先した上で、同一意向内では上位帯との実力ギャップが最も小さい（1450に近い）メンバーから繰り上げることで、試合内の戦力格差を最小限に抑えるため。

### 4. オフレーン2段階ルールの根拠
- **ルール**:
  - MMR 1450〜1549（境界付近の上位層）: 第1希望（メイン）禁止（サブ以下のレーン可: `NON_PRIMARY`）
  - MMR 1550以上（1450+100の圧倒的上位層）: 第1希望・第2希望の両方を禁止（完全オフレーン限定: `STRICT_OFFROLE`）
- **理由**:
  - 上位帯の中にも MMR 1460 のプレイヤーと MMR 1800 の最上位プレイヤーが混在しています。同じ「格下サポート」であっても、最上位層が第2希望（得意なサブロール）で入ると中初級帯の試合が破壊されてしまいます。そのため、MMR 1550 以上の飛び抜けた実力者には完全オフレーンを課す2段階制限により、公平性を担保しています。
