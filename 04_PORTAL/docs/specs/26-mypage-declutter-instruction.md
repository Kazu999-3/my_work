# 指示文26: マイページ（選手カルテ）の情報整理

作成: 2026-11-22（Muse）
対象: 04_PORTAL（/mypage＝/player/[id] の各タブ）
経緯: ユーザー指摘「マイページが情報溢れてゴチャゴチャしてるかも」（2026-11-22）。同日の本番棚卸し（`mypage-inventory-2026-11-22.md`）で、主因は情報量そのものより **同一情報の重複表示** と **全ブロック展開・折りたたみなし** であることを確認した。

## 棚卸しで確認した事実
- 全タブ共通で、バナー＋プロフィールカード＋サマリーカード6枚が常駐し、その直下の総合カルテにも同じ数値が並ぶ。所持コインは3か所、MMR・勝率・通算戦績は3か所、直近10戦は3か所に同一表示。
- 総合カルテは11ブロック・約4〜5画面分で、全ブロックが既定で展開されている（ページ全体に折りたたみが存在しない）。
- データが空のブロック（最大の天敵、対面の苦手側、0戦の対面マッチアップカード10枚）がそのまま場所を取っている。
- スカウティングレポートが総合カルテとソロキュー戦績タブにほぼ同一内容で二重掲載されている。

## やること
- [ ] 常駐サマリーカード6枚は、**総合カルテタブを表示しているときだけ隠す**（他のタブでは要約として残す）。あわせて、同じ数値・同じ顔ぶれのリストは原則として1か所だけに表示するよう重複を解消する。
- [ ] 総合カルテの分析系ブロック（勝ちパターン分析、週刊スタッツ・スカウティング、Hextech 5軸、チーム相性など）は、**全部**を初期状態では折りたたみ（見出しだけ表示）にし、開閉できるようにする。
- [ ] データが空・0件のブロックは、データが無いときは表示しない（「収集中」のプレースホルダ表示もしない）。件数が0の対面マッチアップカードは出さない。
- [ ] スカウティングレポートは**ソロキュー戦績タブに一本化**し、総合カルテ側はレポート本体を置かずリンクのみにする。

## ついでに調査して報告すること（実装はしない）
- 総合カルテ「対面の得意 Nocturne 50% (4戦)」と KTMカスタム分析タブ「vs Nocturne 0-0 (0戦)」の不整合の原因。
- 相性タブの見出し「同チームで3戦以上」と、実際には2戦の行が含まれる点の食い違いの原因。
- 2026-11-22 21:08 の初回表示と 21:11 の再読み込み後で、総合カルテ／KTMタブのブロック構成が違って見えた件（再現するか、キャッシュ・デプロイ等の要因か）。

## やらないこと
- 表示している数値の計算方法（MMR・KDA・勝率・相性など集計ロジック）の変更。
- タブ構成そのものの変更（6タブは維持する前提。変える場合は未決事項として報告すること）。

2. 折りたたみ：**分析系ブロックは全部、初期状態では折りたたむ**（決定済み）。
3. スカウティングレポート：**ソロキュー戦績タブに一本化し、総合カルテからはリンクのみ**（決定済み）。
