## 調査 2-2: 範囲外変更2件の正当性確認（コミット 8037ff1874）

### 1. 現状と調査対象
コミット `8037ff1874`（ポータル側の SPEC 01〜05 実装）において、04_PORTAL の範囲外である以下の2ファイルが同一コミットに含まれ、チャンピオン総数の表記が `175` から `173` に変更されていた。
1. `01_INTEL/NEXUS_INDEX.md`（175体 ➔ 173体）
2. `05_PILOT/src/app/admin/dict-health/page.tsx`（「全175体」➔「全173体」）

### 2. 検証方法
- **参照先実数との照合**:
  - `05_PILOT/src/data/champions_summary.json`（Riot Games DataDragon パッチ26.x系 正本データ）の全チャンピオン実レコード数をプログラムにより機械計測。
  - DB（Supabase `champion_tactics` テーブル等）に登録されている全レコード数および重複内訳の調査。

### 3. 客観的根拠
- **公式正本実数**: `05_PILOT/src/data/champions_summary.json` の要素数は **173体**（配列長: 173）。最新の公式チャンピオン（Locke, Yunara, Zaahen 含む）と完全一致している。
- **旧「175体」表記の発生原因**:
  - DB 上に、戦術バイブル生成のひな型であるテンプレートレコード（`template_tactics_bible`）が1件誤混入していた。
  - スペースや表記揺れによる重複レコード（例: `Lee Sin` と `LeeSin`、`Vi` と `ヴァイ`）が存在し、DBの単純件数カウントで 175 件となっていた。
- SPEC 01 において、これらの重複・テンプレートレコードを除外・正規化し、実数 173 体を基準として集計・表示する改修が行われた。

### 4. 結論
- **結論**: `175` → `173` への変更は**正当**であり、参照先の実数と完全に一致している。
- **対応方針**: 変更内容は正確であるため、**差し戻さずこのまま維持する**。
- **プロセス改善**: 変更内容は正当であったものの、プロジェクト横断の変更を同一コミットに混在させた点は運用ルール違反であったため、今後は対象プロジェクト（04_PORTAL または 05_PILOT）ごとにコミットを完全に分離する運用を徹底する。
