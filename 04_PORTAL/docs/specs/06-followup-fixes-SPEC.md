## 1. 直すもの

### 1-1. KDA表示のフォールバック不整合（不具合）
- 現状：`ktm-admin/MatchHistoryPanel.tsx` は `kda_score` が無い場合に `(kills+assists)/max(1,deaths)` で表示する。このためデス0かつスコア未保存の参加者では、画面の注記「デス0の場合は (K + A) × 1.2」と表示値が食い違う
- やること：フォールバック計算を正本の式（`src/lib/mmr.ts` の `deaths === 0 ? (kills + assists) * 1.2 : (kills + assists) / deaths`）に合わせ、計算は共通関数を参照する形にする。他にも同じフォールバック計算をしている箇所がないか検索して揃える
- 注意：計算式そのもの（×1.2 が意図通りか）は変更しない。これは未決事項として残す

### 1-2. /balancer デスクトップ表の列整理（SPEC 05 の残件）
- 現状：スマホはカード表示で対応済みだが、デスクトップの表は列が多く横スクロールが残っている
- やること：列の優先度を付けて、低優先の列は折りたたみ・行展開・ツールチップ等へ移すなど、横スクロールなしで主要情報（名前 / SoloQランク / KTM MMR / レーン別MMR要約）が読める形にする。移し方の案が複数ある場合は、実装前に案を提示して確認を取る
- 注意：モバイルのカード表示は現状維持。MMRの計算やデータは変更しない

### 1-3. トップページの特典文案の混同防止（SPEC 01 の残件）
- 現状：特典は2種類に整理された（新規登録の初期コイン1,000 / 先輩登録ボーナス500、単位はコインで統一済み）。ただしトップの「初回+500コイン進呈中」は、初期1,000コインの話と混同しやすい
