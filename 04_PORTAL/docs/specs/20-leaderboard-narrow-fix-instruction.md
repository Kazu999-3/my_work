# 指示文20: /leaderboard メタ統計表の狭幅表示の修正

作成: 2026-11-22（Muse）
対象: 04_PORTAL
根拠: Portal SPEC 19 の375px表示確認（実装側の報告）で × として特定された件。SPEC 19 では「確認と報告」が完了条件だったため未修正のまま残っている。

## 現状の問題
- /leaderboard のメタ統計表で、先頭列を固定する sticky 指定が `<td>` 側に漏れている箇所があり、375px相当の狭幅で表示がずれる（実装側が localhost 375×812 で実測し、DAILY_LOG に × として報告済み）。
- なお同じページの勝率マトリクス表は ○ だったため、対象はメタ統計表側のみ。

## やること
- [ ] メタ統計表の sticky 指定の漏れを特定し、勝率マトリクス表（○だった側）と同じ方式にそろえて修正する。
- [ ] 修正後、375px相当の幅で /leaderboard を再確認し、結果を報告する（確認方法も明記する）。

## やらないこと
- /leaderboard の他の表示・集計ロジックの変更。
- SPEC 17 の他の対象ページの再変更（375px確認で ○ だったもの）。

## 完了条件
- ローカルで `npm run build` が成功してから push すること。
- 修正箇所（ファイル名）と、修正後の375px確認結果を報告すること。

## 未決事項
- なし。判断が必要な点が出たら、決めずに報告すること。
