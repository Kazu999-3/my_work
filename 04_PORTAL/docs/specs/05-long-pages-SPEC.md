# SPEC：長いページの折りたたみ・絞り込み・導線の改善（KTMポータル）

対象：https://my-work-8jbd.vercel.app/balancer 、 /festival/pick 、 /history 、 /mentorship 、 /guide
Antigravityへの渡し方：このファイルをリポジトリに置き「このSPECを読んで実装して」と指示する。範囲が広いので、ページごとに分けて実装してよい。

## 1. 目的
情報量が多いページで「探せない・長い・重い」状態をなくし、目的の情報にすぐ届くようにする。機能とデータは変えない。

## 2. 現状の問題（2026-11-19 本番確認）
- /balancer：92名×11列の表で横スクロールが必要。下部のフローティングバー（参加人数・チーム分け実行など）が表の行に重なる。「希望の強さ」が管理者のみ変更可で無効化されている理由、「⚔️挑戦」列の意味が常時見えない
- /festival/pick：170体を14地域すべて展開表示。チャンピオン名が「マスター・…」のように切れる。右上の開催情報ボタンも途中で切れている。1体抽選／5体抽選／テーマおまかせダイス／大会式ドラフト(5v5)／少人数ドラフト抽選 の違いの説明がなく、参加人数スライダーと対戦形式ボタンの関係も分からない
- /history：約50試合が縦に長く、先頭3試合は展開済みでさらに長い
- /mentorship：「1名募集中」なのに先頭カードはすべて「相談ペア結成中」で、募集中のカードが探せない。カード内の活動時間が「21:00〜24:00 /」「21:00-」と途切れて表示される
- /guide：内容は充実しているが非常に長く、目次・検索導線がない

## 3. やること
### 共通
- [ ] 各ページに「トップへ戻る」導線と、セクション単位の折りたたみ（初期状態は主要セクションのみ開く）を入れる
- [ ] 文字が途中で切れる箇所は、折り返し表示かツールチップ（全文表示）で読めるようにする。対象：/festival/pick の開催情報とチャンピオン名、/mentorship の活動時間

### /balancer
- [ ] 列の整理：スマホ・狭い画面では優先度の低い列を畳む、名前列を固定する等で、横スクロールなしに主要操作（参加チェック・希望レーン）ができるようにする
- [ ] フローティングバーが表の内容に重ならないよう、下部に余白を確保する
- [ ] 無効化されている操作には理由を常時表示する（例：「希望の強さは管理者のみ変更できます」）。「⚔️挑戦」列には見出しに短い説明を添える

### /festival/pick
- [ ] 地域セクションを折りたたみ式にし、チャンピオン名の検索・絞り込みを追加する
- [ ] 抽選方式ごとに1行説明を追加する（何人向けか、何体配られるか、どう違うか）。参加人数と対戦形式の関係（例：6名＝3v3）もその場で分かる表示にする

### /history
- [ ] 初期表示は全試合を折りたたんだ状態に統一し、展開は任意にする（または先頭1試合のみ展開）。ページングか「さらに読み込む」方式に寄せ、初期の縦の長さを抑える

### /mentorship
- [ ] 「募集中のみ」フィルタを追加し、募集中カードには目立つバッジを付ける。左メニューの「1名募集中」と実態が一致して見えるようにする

### /guide
- [ ] ページ内目次（タブ内アンカー）を追加し、目的のFAQ・ルールへ直接飛べるようにする

## 4. やらないこと
- 機能・データ・計算ロジックの変更
- ページURLや導線構成の変更
- 全面リデザイン

## 5. 完了条件
- [ ] /balancer で、スマホ幅でも参加チェックと希望レーン変更が横スクロールなしでできる
- [ ] /festival/pick で、名前でチャンピオンを検索でき、抽選方式の違いが説明だけで分かる
- [ ] /history の初期表示が全折りたたみで短く収まる
- [ ] /mentorship で募集中のカードだけを1操作で絞り込める
- [ ] 切れて読めなかった文字（開催情報・チャンピオン名・活動時間）が全文読める

## 6. 未決事項（エージェントが勝手に決めない）
- /balancer の列を畳む優先順位（どの列をスマホで隠すか）
- 折りたたみの初期状態の細部（全閉じか、主要セクションのみ開くか）
