# 指示文30: マイページの希望設定の自動保存と分析ブロックの表示調整

作成: 2026-11-23（Muse）
対象: 04_PORTAL（マイページ）
経緯: ユーザー要望（2026-11-23）。指示文26で入れた「全ブロック折りたたみ開始」の一部見直しを含む。

## やること

### 1. 希望設定を保存ボタンなしで反映する（自動保存）
- マイページの希望設定（希望レーン、格上との関わり方、その他のプロフィール設定）を、項目を変更した時点で自動的に保存されるようにする。保存ボタンの押下は不要にする。
- 保存の状態が分かる小さなフィードバックを出す（例：保存中…／保存しました）。保存に失敗した場合はエラーを明示し、黙って未保存のままにしない。
- 保存先のフィールド・値・バランサー側の読み取りは現行のまま変えない。

### 2. 「チーム相性 ＆ シナジー分析」は折りたたまない
- 指示文26の「全ブロック折りたたみ開始」の対象から、このブロックだけを外し、常に開いた状態で表示する。

### 3. 「週刊スタッツ」と「スカウティングレポート」を表示から外す
- 週刊スタッツのブロックをマイページから撤去する。
- スカウティングレポートを撤去する。ソロキュー戦績タブの本体表示と、総合カルテ側のリンクバナー（指示文26で設置）の両方を外すこと。
- いずれも表示の撤去のみとし、元データや計算ロジックの削除はしない。

### 4. 「Hextech 5軸能力」と「勝ちパターン分析 (Victory Blueprint)」の開閉を同期させる
- この2ブロックの折りたたみ状態を連動させる。片方を開閉したら、もう片方も同じ状態になる（開く操作・閉じる操作のどちらでも）。
- 初期状態は現行どおり（折りたたみ開始）でよい。連動するのは開閉の操作である。

## やらないこと
- 上記以外のブロックの開閉仕様の変更（指示文26の「折りたたみ開始」「空ブロック非表示」は、項目2・3の対象を除き維持）。
- 設定項目そのものの追加・削除、バランサーのロジック変更。

## 完了条件
- `npm run build` が成功すること。
- 項目ごとに、変更箇所と動作（自動保存のタイミングとフィードバック、連動開閉の挙動）を報告すること。
