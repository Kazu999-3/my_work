# SPEC 18：マイページのカスタム関連設定のデザイン刷新

## 目的
マイページ（プロフィール設定）の中でも、カスタムのチーム分けと帯編成に直接効く設定群を、初めてのメンバーでも「この設定を変えると何が起きるか」が分かるデザインに作り替える。2026-11-22 の監査で、設定の意味説明の不足、保存挙動の混在、選択状態の分かりにくさが複数指摘されたことを受ける。

## 対象の設定（カスタムに影響するもの）
- 第1希望レーン／第2希望レーン
- NGレーン（NG1・NG2 を含む）
- 希望レーンの強さ（レーン優先度）
- 対面保護（同じ試合での格上対面の可否）
- 帯の繰り上げ許可（格上許可の3択）

※格下サポートフラグは運営側が付ける設定なので対象外（指示文13で対応）。外観・テーマ等の設定も対象外。

## SPEC 12 との関係
SPEC 12 のプロフィール側の項目（格上2設定の整理、設定のグルーピング、説明不足の解消）と重なる部分は、本 SPEC を優先する。SPEC 12 側では、その部分は本 SPEC で対応済みとして読み替えてよい（バランサーの運営分離、結果登録の管理者チェック復活など、その他の項目は SPEC 12 のまま）。

## やること
- [ ] 対象の設定を「カスタム参加の設定」として1か所にまとめ、外観などカスタムに影響しない設定と視覚的に分ける
- [ ] 並び順を「上から順に設定すれば終わる」順にする（希望レーン → NGレーン → レーン優先度 → 対面保護 → 帯の繰り上げ許可）
- [ ] 各設定に「変えると何が起きるか」の一文説明と具体例を付ける（例：対面保護なら「格上の相手とレーンで当たるかどうか」など、監査で説明不足とされた点に対応）
- [ ] 画面の上部に「今のあなたの設定」の要約を文章で表示する（例：「JG優先／格上対面OK／人手不足なら上の帯もOK」のように、現在の設定値から自動で組み立てる）
- [ ] 選択肢は、意味が言葉で分かるボタン形式にし、現在の選択が色だけでなく文言でも判別できるようにする（「選択中」の明示）
- [ ] 保存の挙動を統一する（即時反映と保存ボタンの混在をなくし、保存されたことが分かる表示にする）
- [ ] 用語は SPEC 14 の統一結果に従う（「こだわり度」などの内部呼称は使わない）

## やらないこと
- 設定の意味・保存先・既存データの変更（既存ユーザーの設定値はそのまま引き継ぐ）
- バランサー側のチーム分け・帯編成ロジックの変更
- 新しい設定項目の追加

## 完了条件
- 初めて見る人が、説明を受けなくても各設定の意味と効き方を言える状態になっている
- 「今のあなたの設定」の要約が、実際の保存値と常に一致する
- 既存ユーザーの設定値が、デザイン刷新の前後で変わっていない
- ローカルで `npm run build`（04_PORTAL）が成功してからプッシュする

## 未決事項（エージェントが勝手に決めない）
1. 要約文の文体と、設定画面の色・レイアウトの細部
2. 初回設定をステップ形式（順番に案内する形）にするかどうか
3. 各設定の説明文の最終文案
