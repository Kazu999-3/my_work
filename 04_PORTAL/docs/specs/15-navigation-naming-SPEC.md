# SPEC 15：導線とページ名の是正

## 目的
ページの「名前・入口・案内」と実物が食い違っていて、初めて使うメンバーが迷ったり行き止まりになったりしている箇所を直す。2026-11-22 の UX 監査（ブラウザ実地：portal-ux-audit-browser.md／コード監査：portal-ux-content-audit-code.md）に基づく。本 SPEC は文言と導線の是正のみで、機能追加はしない。

## やること
1. **/analyzer の名前と行き先の是正**
   - [ ] サイドバーの項目名「勝敗予想」（Sidebar.tsx:231）とトップページのカード「勝敗予想 & KTMショップ」の行き先・文言を、実物（ソロQ個人分析「LoL パーソナル深層アナライザー」）と一致させる。チーム勝敗予想の機能はこのページに存在しないため、「勝敗予想」と読める入口からは辿れない形にする。
   - [ ] ページ内の目的文「ノーマルやカスタムを完全排除した勝敗予想です」（analyzer/page.tsx:210 周辺）の矛盾を是正し、ソロキュー個人分析であることが分かる文言にする。ツールの呼び名が「LoLディープアナライザー／LoL パーソナル深層アナライザー」の複数ある点も、表示名を1つに揃える。
   - [ ] 一般メンバーが行き止まりになる状態（analyzer/page.tsx:178-180「管理者ログインが必要です」＋管理者ログインへの誘導のみ）を解消する。このツールが管理者限定であること、一般メンバーは対象外であることを案内文で明示し、管理者ログインへ進む以外の戻り先（トップ等）を示す。機能の開放はしない。
2. **サイドバー導線の欠落の是正**
   - [ ] カジノへのリンクがサイドバーに出ない状態がある（ブラウザ監査で複数ページで確認）。カジノへの項目を常時表示する（名称は項目5の統一先に従う）。
   - [ ] /replay-paths と /analyzer のナビ項目自体がない（Sidebar.tsx:223-240。/analyzer は「管理画面」の activePrefixes に含まれるだけ）。リプレイの道筋への項目を追加し、管理画面へのリンクも含め、各機能へサイドバーから辿れる状態にする。表示条件（ログイン状態・管理者かどうか）で出し分ける場合は、その条件を実装時に報告すること。
3. **/replay-paths の案内とページ名**
   - [ ] 合言葉入力画面（replay-paths/page.tsx:90-91）に、このページが何か（リプレイの移動経路マップ）の説明と、合言葉の入手先（どこで共有されているか、誰に聞けばよいか）の案内を追加する。現状は「共有された合言葉、またはURLのキーを入力してください」だけで、持たない人が行き止まりになる（ブラウザ監査で致命的）。
   - [ ] ページ名「リプレイの道筋／リプレイ道筋マップ」の混在を1つに統一し、サイドバー・パンくず・ページ見出しで同じ名前を使う。
4. **トップページの説明と次回案内**
   - [ ] トップページに、KTM が何か（LoL のカスタムコミュニティであること）が初めての人に分かる説明を追加する。現状は「利用ガイド」まで行かないと分からない（ブラウザ監査）。既存の冒頭一文（page.tsx:43）は目的の要約として残してよい。
   - [ ] 「次回カスタム」カードが表示されない問題を直す。ブラウザ監査時（2026-11-22）は次回カスタムのカード自体が出ず、次に何をすればいいか・次回日程の案内がなかった。次回日程が未定の場合でも、その旨と確認先（Discord 等）が分かる案内を出す。
5. **/casino の名称整理とログイン表示**
   - [ ] 名称の混在（カジノ／KTM Sovereign Casino & Shop／勝敗予想 & KTMショップ／長者番付）を整理し、サイドバー・トップカード・ページ見出しで同じ系統の名前を使う。「Sovereign」のような説明のない内部ブランド英語（CasinoHero.tsx:19 ほか）もこの整理に含む。※通貨表記（コイン／pt／ポイント／チップ）の統一は SPEC 14 の範囲であり、本 SPEC では触らない。
   - [ ] ポータルにログイン済みでも「Discordでログイン」ボタンが表示される表示条件を是正する。ログイン済みの人には再ログインが必要に見えるボタンを出さない（カジノ側の認証状態が別に必要な場合は、その理由を文言で説明する）。
6. **/mypage の入口と着地先の一致**
   - [ ] /mypage がダッシュボードではなく設定タブ（/player/[id]?tab=settings）へ直行する問題を是正する（mypage/page.tsx:22-23、既定値 "settings"）。トップページの「マイカルテを開く」や /mypage 自身の説明文は戦績カルテを前面に出しているのに、着地が設定タブで約束とずれている。入口の名前・説明と着地先を一致させる（着地先の変更か、入口側の文言の変更かは未決事項1に従う）。

## やらないこと
- 機能追加・機能変更（/analyzer へのチーム勝敗予想の追加、/replay-paths の合言葉方式そのものの変更、/mypage のダッシュボード新設などはしない）
- 用語集の新設と、呼び名・用語の全般統一（SPEC 14 の範囲。「下位帯／中初級帯」「こだわり度」等の用語統一も SPEC 14）
- 通貨表記の統一（SPEC 14 の範囲）
- バランサー画面とプロフィール設定の構成変更（SPEC 12 の範囲。2つの「格上」系設定の整理を含む）
- 個別ページの操作フロー・入力欄・ボタンの改善（SPEC 16 の範囲。結果登録の説明不足、大会ピックのボタン順など）
- 狭幅レイアウトの修正（SPEC 17 の範囲）
- /login ページの文言是正（監査でログイン画面自体が未確認のため、対象に含めない）

## 完了条件
- サイドバーとトップカードのどの入口からも、名前から期待する内容と実際のページが一致している
